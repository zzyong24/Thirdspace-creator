# T-972 内容雷达页面加载失败

用户在新安装版打开内容雷达出现整页错误，编号479389334。目标：定位真实异常，恢复内容雷达加载，不清除业务数据，不以空页面掩盖失败。

验收：失败路径回归测试、安装版公共查询及真实页面验证；需要更新安装包时沿用本地官方入口。全局既有对账漂移仍归T-916。

## 根因与实现

解密本机sidecar日志：16:03:58首次JSON解析异常，之后各查询持续报XX000；截图digest479389334对应同一异常。关闭应用后备份至`~/.creatoros/backups/t972-before-recovery/db`，重启原库后公共查询恢复。在副本上只读执行全量任务查询，4057条任务、约15.9MB payload，稳定复现JSON异常并使随后的SELECT 1失败；说明是大响应破坏运行中协议解析状态，不能据此判断磁盘数据损坏。

持久任务列表此前全量SELECT再JavaScript slice；改为数据库LIMIT/OFFSET和独立COUNT，保持账号隔离与排序。雷达只需任务状态计数，改为读取状态列，去掉全部payload加载，且不再漏掉1000条以外的状态。

回归：新增300条大载荷的真实PGlite分页用例，旧实现导致进程持续无响应被终止（不是断言红测）；改后任务服务9项通过。真实副本状态投影4057条、分页1000条和后续SELECT 1通过。前端tsc通过。保留原库，未删除任务或业务内容。

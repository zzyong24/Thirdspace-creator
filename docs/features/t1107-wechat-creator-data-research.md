# T-1107 视频号与公众号创作者数据调研

## 用户目标与阶段

用户2026-10-09要求研究视频号和公众号能否类似现有抖音、快手、小红书拉取创作者数据。本轮为 PLAN 的能力调研，仅提供经来源核对的结论与接入建议；不修改运行时、平台能力表、登录凭据、真实任务或架构，不将建议冒充批准实施。

## 交付与验收

- 核对官方开发文档、创作者后台入口，区分官方稳定接口与本人授权登录后台采集的可行性。
- 区分自己/授权账号的作品、阅读播放、互动、粉丝等经营数据，以及其他创作者公开数据；明确权限、口径、时间窗和未知项。
- 只读盘点现有平台适配器、凭据保存与任务调度接缝，说明可复用部分与缺失部分。
- 交付中文报告、能力对照表、来源链接和一张流程图；标注资料核实与真实账号未实测的区别。
- 独立核查主要结论，检查文档与链接，记录真实完成证据；产品实现另需服务契约、归属与适用评审。

## 边界

不读取Cookie或浏览器profile，不对用户账号扫码或采集，不重启正在工作的CreatorOS，不使用第三方出售数据充当官方能力，不将小店/直播电商接口视作普通视频号内容经营接口。

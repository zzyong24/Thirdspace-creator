# T-1022 快手账号绑定、作品目录与创作指标

> 用户已确认采用本机自动化路线。依赖 T-1020 的平台能力合同与账号级快照；不以开放平台应用、OAuth 回调或 scope 为用户本人账号采集的前置条件。本地现有 `JY_IPAgent` 只证明分享链接解析，不能冒充完整创作者账号采集。

## 用户流程

用户在 CreatorOS 账号页选择“快手”，系统打开该账号独立的本机浏览器档案及创作者页面，用户亲自登录或扫码。系统从正常登录页面核验稳定平台身份后才绑定；重复绑定同一身份复用原账号，错号拒收，不读取其他浏览器或其他产品的 Cookie。绑定后可手动同步，并按既有调度错峰采集本人作品及账号数据。验证码、登录失效或访问限制需要用户自己完成或重连，程序暂停该号，不绕过验证。

作品页显示当次可枚举的完整目录或明确的已验证范围，附上同步时间、进度、来源和不可用字段。作品数、播放、点赞、评论、分享、粉丝等各自按真实页面字段映射，缺失就是不可用，不由其他指标推断，也不把 `pending` 当作公开状态。失败保留上次完整目录；两个账号的登录档案、任务、指标快照和错误互相隔离。没有快手绑定时仍可在项目中创作快手目标内容。

## 实现边界

先在用户正常打开的快手创作者页面核对登录身份、作品管理目录、分页终止方式及各指标的可见来源，记录字段、单位、时间窗、页面位置和真实样本。只有稳定账号 ID、终页证据及字段单位/时间窗口样本回执齐备，对应能力才从 `unavailable` 变为 `ready`；未证实的能力继续不可用。正式浏览器档案键包含 CreatorOS `userId + platform + verifiedAccountIdentity`，扫码临时档案在超时、取消或错号后清理。采集运行在 worker，写入经 backend service port 做 `userId + accountId` 归属校验；浏览器档案与凭据只在本机，不进入 Growth/Activity。若某字段或完整终页无法由页面核验，保留已验证范围并标 partial，不伪装为全量。页面变化只使对应能力降级，不让已验证字段消失。可见性未知时本机展示、云端停止该作品出站；确认隐藏/删除时走 T-1020 墓碑与迟到快照保护。

开放平台 API 可以作为未来单独适配器。它的 token、应用密钥和浏览器登录态不得混用；本任务不需要先创建 OAuth 回调桥，也不展示未接线的授权按钮。发布是另一项有用户确认的动作，采集或绑定不会触发发布。

## 验收

至少一个用户亲自登录的快手账号完成身份核验、作品目录分页和可得指标与创作者页面逐项核对；第二号验证独立档案、错号拒收与其中一号失效不影响另一号。覆盖真 0/缺值、分页中断与重试、重复任务、过期登录、页面字段变化、重启恢复、可见性未知、旧完整目录保留和云端零误出站。无真实页面证据的字段及完整性不记 PASS；源链接解析、夹具或单测不能代替 CreatorOS 真机验收。

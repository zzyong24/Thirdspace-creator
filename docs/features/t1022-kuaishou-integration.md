# T-1022 快手账号授权、作品目录与创作指标

> 待 T-1018 用户审核与独立评审；依赖 T-1020。快手本地参考仅证明分享链接和单视频浏览能力，不把它当作创作者账号数据已接通。

## 来源选择与实现边界

先在可用的快手开放平台应用主体下核对授权 scope、回调、token 生命周期、用户身份、作品列表和作品/账号指标的**实际权限与返回字段**；以[官方用户资料文档](https://open.kuaishou.com/platform/openApi?menu=17)为已发现的粉丝数参考，但它不证明作品表现权限。若官方权限无法覆盖完整创作者后台数据，再针对用户自己授权账号评估本机浏览器的正常页面读取，形成来源/可用性记录和独立复审；不引入绕过验证码、逆向签名或代理池作为产品能力。`JY_IPAgent` 的快手链接识别可作输入解析参考，不迁入其平台共用 Cookie 目录结构。

## 用户流程与能力口径

账号页“绑定快手”只在所选接法和回调真正可用时开放。用户完成官方授权或本机官方页面登录后，系统回读真实平台身份并与既有绑定核对。作品目录、粉丝总量、播放、点赞、评论、分享等按各字段真实可得性分别声明；没有权限的能力显示原因，不生成假数字，也不因缺一项让已可用能力失效。作品支持全量目录或明确的已验证范围，不用最近页数冒充全量；分页、限速、登录失效、错号、重启恢复遵守 T-1020。

## 验收

提供官方 scope/字段可用性清单与真实授权回执；至少一个真实授权账号完成身份与作品/账号指标对照，完整性范围如实展示。第二账号或错号验证隔离；断网、过期授权、平台返回 0/缺失、分页中断及重复任务保留旧真值。若官方和正常页面均无法提供某字段，该能力明确标为不可用并留下后续数据来源需求，不能以模拟数据通过本任务。发布能力另按既有发布确认边界验收，不随采集授权暗中开启。

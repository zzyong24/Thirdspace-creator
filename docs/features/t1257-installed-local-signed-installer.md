# T-1257 当前安装版的本地签名安装包

2026-10-12 用户要求将当前已安装版本打成本地安装包发给朋友，并随后明确“只做本地签名，不提交 Apple”。

交付来源是 `/Applications/CreatorOS.app`（1.2.0、arm64），不是当前未提交源码。复用已安装二进制，仅对副本进行 Developer ID 签名并封装 DMG；不重建业务代码、不修改压缩运行时或其完整性哈希，不替换当前安装，不发布或触发远程构建。

验收：记录来源主程序和 sidecar SHA256；副本签名严格验证通过；sidecar 字节保持一致；DMG hdiutil verify通过；挂载后包内应用签名和内容核验通过；输出文件与 SHA256。Apple 公证不在用户确认范围，不把本地签名描述为公证通过。当前安装正在使用，避免替换或新开同数据目录进程；独立安装启动尚未验证时如实说明。

流程：已读取 product-to-code-orchestrator 3.29.0，项目版本一致。当前项目阶段4-build，本任务只执行现有安装制品的本地交付，不改变全局阶段，不改产品方向、架构、数据归属或服务契约。packaging-creatoros-release 的源码构建冻结检查发现大量他人未提交改动，因此不运行源码重建；用户明确指定当前安装版，采用其副本作为冻结来源。

# T-1047 小红书组图创作、画布复用和工作流调研

2026-10-02 用户纠正图文工作台方向：核心是出图、组图生成、一致性和工作流衔接；现有画布覆盖大量编辑能力，快图保留作为可改造的辅助细调工具，不以单张设计编辑器代替图文创作工作台。

本任务查证小红书官方创作/发布流程，调研可实际运行的开源组图生成实现，核对现有画布、生图 Skill、稿件/图卡/素材/版本服务。产出有引用和事实/推断区分的研究结论、复用映射及一张用户流程图，明确从一份内容到组图的真实操作与单页重做、整组一致性、封面/正文/简介/标签/检查的衔接。

这是已授权的方向调研；本轮不依据未经评审的假设替换生产图文主流程。保留已集成快图的源与能力，后续方案优先复用画布和既有生成/采纳链。不得把搜索摘要当作完整上游流程或把设计建议当作小红书硬规则。

## 行为与范围

- `capability` 仍须为非空字符串；`provider`、`modelName` 必须实际存在且类型为字符串，允许空字符串，保持与设置保存及种子占位的既有数据形状一致。缺字段、非字符串、数组行、非法 kind/version/models 继续拒绝，校验失败不写入任何行。
- 占位行完整往返；已配置行保留模型、协议、地址、settings、isDefault。空凭据仍沿用原保留既有密钥语义；跨机器密文依旧报告不可恢复且不写坏值。
- 密钥仅服务端解包并重新加密；公开 DTO、日志和测试报告不暴露真实密钥。
- 修改仅限 settings 导入解析器、对应 service round-trip 测试和验收记录。无数据库 schema、迁移或前端新表面。

## 验收

1. 先运行包含合法继承占位与已配文本/图片模型的往返红测，当前 parser 应拒绝；修复后同机导出导入读回一致，并确认默认模型仍可作为 copy.generate 的回退。
2. 缺 provider/modelName、错误类型、数组行继续全文件拒绝；原同机密文、跨机器不可恢复、无密钥保留已有值与 capability 覆盖回归通过。
3. 用仅含模型配置的隔离验收库导入真实本机导出形状，12 行均成功；随后 T-1029 使用该库的真实配置走生成候选、审阅、采纳、刷新。此项只发送合成测试内容，不读取或改变原桌面作品。

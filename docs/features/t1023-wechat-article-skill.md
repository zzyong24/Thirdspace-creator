# T-1023 公众号长文写作 Skill 与项目稿件闭环

> 待 T-1018 用户审核与独立评审；依赖 T-1020 的 `wechatOfficialAccount` 内容目标语义与现有 Agent 工具边界。本地来源：`moonlit-wechat-article`、`moonlit-content-engine`；`moonlit-wechat-publisher` 只用来界定未来发布边界，本次不接草稿箱或群发。

## 方法包与账号品牌

将本地 Skill 中“主张→事实/经历→因果→正文→逻辑审读→视觉简报”的通用方法整理成可版本化的公众号写作 Skill 包；输出契约包括标题候选、摘要、分节正文、事实待确认项、视觉简报和引用的项目/素材版本。月明身份、宇航员形象、绿色品牌样式、本机 `works/YYYY` 路径作为**对应账号的品牌覆盖**，不得写死进所有用户的系统方法。导入时记录源 Skill 版本、来源和许可/归属；脚本资源须逐一审查，不因为目录里有 `scripts/` 就自动可执行。

## 创作与发布流程

项目中新增“公众号长文”目标，不借用 `wechatVideo`。无公众号账号也能先写文章；编导按当前确认的 Brief、稿件、真实素材和用户要求选择方法，生成候选，不直接写当前稿。用户可逐段审读/采纳，保存文章版本并按 T-1019 可保存自己的创作提示词；缺事实或素材时显示待确认，不编经历。配图沿项目资产/画布引用与版本交接，视觉简报不等于图片已生成。排版预览本机完成。本次不接入写微信草稿箱、更新草稿或群发；这些动作需要另立发布 SPEC，确定账号资格、用户确认、状态转移、幂等与真实回执后再显示入口。

## 验收

同一选题分别在月明账号和无品牌新账号生成候选：前者按其品牌配置，后者没有月明身份/目录/视觉标记。错账号素材不得进入上下文；未采纳候选不覆盖文章版本。刷新后文章、配图清单、引用版本仍可回读。仅写作不触发草稿/发布 API；预览只产本地文件且没有草稿/群发假按钮。Skill 缺失或可选配图失败时已有稿可继续审读，不让可选质量门反杀写作完成。

# 账号组页面规范

适用：CreatorOS新增、重构、优化的用户页面。用户于2026-10-19撤销OilUI要求，要求参照之前已稳定页面的风格；保留原版丰富工作台，不引入第二套主题或视觉语言，不再做A/B新风格探索。

## 流程与归属

先盘点相关已有稳定页面、tokens和组件，保留同视口、数据与状态的改动前基线，从真实用户任务核对对象、工作区与操作路径。产品范围、合同、数据和适用功能门禁继续由product-to-code-orchestrator负责，不加载已撤销的页面设计技能或其审美门。

设计说明、截图、原型和实际检查记录放在任务目录，直接对照原有稳定页面；不另引入探索生成器或强制评分流程。未渲染、未核实际视觉或未接业务必须如实记录。文档原型与产品交付分开，截图不能代替真实操作、保存与读回证据。

## 视觉与组件

正式实现复用 `frontend/src/styles/tokens.css`，不另造主题：品牌#6d4aff，画布#f8f9fc，正文#171a25，次文#667085；语义状态沿用现有tokens。中文使用现有Noto Sans SC与系统回退，数字tabular-nums。正文14–16px，数据24–32px，页面标题24px；不靠缩小到12px以下塞信息。

控件圆角8px、卡片12px、面板16px；页边24px、区块20px、内部16px为默认。正式组件沿用Button、Input、DropdownMenu、Dialog、PlatformIcon和图表系统；图标沿用Lucide，不用emoji充当平台身份。

首页沿用现有DashboardPage的问候、五指标卡、三列六卡和卡片内列表；不能以减法删除继续创作、待办、热门选题、最近发布、趋势或创作建议。保持SectionCard、MetricCard与当前列表密度。作品页仍按一期内容与平台版本的关系组织，不把首页卡片规范强加到明细表。普通信息不竞争品牌主操作，重点颜色面积约10%以内；不新增发光、玻璃、渐变装饰。保留对象名称、当前状态、指标口径与下一步动作，删重复说明。

## 全局语法

- 账号组选择沿用侧栏底部原账号位置，个人身份单独保留；组名长时有完整可访问名称。
- 平台与账号是页面筛选；同平台多账号先选平台再选具体账号，不改变定位。
- 首页平台条只筛指标、发布、趋势；继续创作、待办、热门选题与建议始终保留组上下文。全部数据区共享筛选和时间窗口。数字标题直接写单位/口径，未知为—、真实0为0。
- 未绑定、登录过期、未采集、能力不支持分开表达；不得统一标“失败”或仅禁用无原因。
- 当前页只有一个主要动作；每行最多一个直接动作，管理动作放更多。状态词与颜色配合，纯图标有可访问名。

## 图表规范（用户认可原版后追加）

用户要求可视化更美观，保持已认可的工作台结构。正式实现复用ChartFrame、ViewsTrendChart、HorizontalBarsChart与ECharts tokens，不再建立第二套生产图表系统。

- 有真实逐日数据时，趋势线使用品牌紫、约2–3px线宽和低透明度同色面积。日期横轴、带单位的数值纵轴、等距刻度与零基线必须可见；淡网格不抢内容，轴/图例至少12px，可访问摘要保留。
- 图表阅读顺序为标题与单位、当前范围、数据摘要、图、来源/更新时间。分析页先看图，再看原始表，避免图被长表推到页面底部；首页六卡顺序不变。
- 同口径作品比较用横条，名称和值一行，条从0开始、共同刻度。按已知数据显式排序；数值与颜色同时表达结果，不能只用长短猜值。点击作品复用对应内容复盘入口。
- 播放、阅读、粉丝与完播率不共轴；不可比较的平台拆开。比例只有真实分子/分母时才画，未知不画零长条或空圆环冒充测到0。
- 没有数据时保留轻网格、明确缺失原因与账号/采集恢复入口，不画虚假曲线。只有一个有效快照时显示单点与明示提示，多次真实采集后才画趋势。
- 用户指出无坐标不可读后，当前原型撤回没有每日明细的轮廓折线。改为已知范围：日期09/24—10/03；播放量纵轴0—12,000次，每3,000一刻度；10,260与167只作为上下界，发生日期未知，不能当逐日点位。作品比较仅用截图的20,570、10,427、333、243，共同0—25,000次轴、每5,000一刻度；四条历史样本不能当组全量或每日新增。
- 图、摘要、比较表共享组/平台/账号/日期；切到其它平台、最近7/30天或空组时，不复用旧样本。有部分失败时保留其它图与合法入口。

## 状态与响应式

每页覆盖正常、空、加载、错误、权限、长内容与部分平台失败。错误留在触发位置，失败不丢输入或改用别的账号。已有内容更新保留原布局；切组马上更新身份标识并清理旧组数据可见区，取消旧请求/以scope generation拒绝过期响应。

1366×900、1280×800和宽屏优先；1024窄窗折叠侧栏、比较表可局部横滚；390宽度是原型极限检查，正式桌面最小窗口另依宿主约束。每表面一个主滚动区，浮层不被裁切。缩放200%仍可读。键盘Tab/Enter/Esc与焦点返回；reduce-motion下不依赖动画。

正式组切换保留后台任务；前台生成或表单提交沿用离开提示。同页打开弹层复用本地路径，不等待整页刷新；轮询限制在途请求、卸载和scope变化不得回写。触及这些路径必跑LED-047。

## 交付验收

使用对应viewport、同数据和状态留前后图；截图必须实际看过。完整改版选定方向后独立视觉评审，另做任务走查；不把截图当保存或发布成功证据。保存须重新读取，平台发布须真实回执。记录删掉的文案、细节修正、可操作边界和未验证项。

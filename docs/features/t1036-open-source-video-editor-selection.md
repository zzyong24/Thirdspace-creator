# T-1036 开源视频编辑组件选型与兼容验证

范围：隔离技术验证与选型，不修改生产依赖、API、数据或用户媒体。2026-10-01。

## 任务来源和依赖

依赖 T-1035 已评审需求；先核对开源代码、许可、React/Next 与现有 HyperFrames/Asset 适配，用隔离探针选择可实际复用的时间轴/预览能力，不照搬闭源附件。

整体需求：[T-1035](t1035-video-production-workbench.md)，本子任务不得替代或缩减父任务的完整用户结果。

## 范围

以 T-1035 用户结果为依据，先调查可复用开源，不预先决定全部手写。候选包括官方 OpenCut 主仓/Classic、React Timeline Editor、同名但不同来源的 Clawnify OpenCut；Twick 为公开源码但有 Sustainable Use 条件，单独标注，不当 MIT。ChatCut 与用户附件只作交互参考。

比较项目 identity、固定 commit、许可、维护状态、可复用模块、React 19/Next 16兼容、现有 props/合成器适配、离线桌面打包及长片性能。优先组件级复用；整体内核替换必须证明确有收益并更新父 SPEC/DEC 后评审，不能引入第二资产或任务账本。

## 有界探针

一个具体问题：候选是否能接受 CreatorOS 方案的稳定 item ID、播放头与显式时间改动，并驱动现有合成预览？时间盒 120 分钟，工作区 /tmp/creatoros-t1036-probe，源码只读；记录依赖和复用 attribution。比较失败保留原结果，不运行用户生产工程、不部署。

## 验收

有来源与 commit 的选型矩阵；一个最小集成探针的真实结果；选定复用边界与降级方案；记录 license/attribution 和维护成本。调研通过不代表视频工作台已可用。

组件只将用户明确的选中、播放时间和时间改动传出；不选素材、不做语义编排。用临时生成的音视频/图片和明确标记的测试工程，禁止读取用户媒体目录、Cookie、账号凭据或生产数据库。第三方仓库只读，不运行其 install/build 脚本；npm 已知官方包安装禁用生命周期脚本。探针的 Next 启动/构建只执行本任务自己编写的代码与已审阅入口。

工作目录 /tmp/creatoros-t1036-probe 仅用于执行。脱敏样例源文件、锁文件与包版本、安装/构建命令回执、输出 hash、观察记录和必要截图必须持久保存到项目内 docs/research/evidence/t1036/；选型矩阵引用这些证据与 hash。停止本任务自建服务器后，持久证据不随临时工作目录清理。临时目录仅在后续不再需要时清理，不删除用户目录。评审与研究验收使用文档证据，本任务没有产品页面，不使用制作工作台的 UI 验收列；生产接入仍由 T-1037/T-1038 定稿合同。

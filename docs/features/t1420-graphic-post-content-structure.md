# T-1420 小红书图文正文与多页图片

2026-10-26 用户指出现图文把长文铺在黑色图片上，不是内容重组。用户期望根据当前内容组织若干张图片，每页讲清一个内容点；独立的发布正文采用小红书图文表达，而不是重复整篇原文。图文工作台不展示“开源来源与许可”与含糊的“发布与交付”区块；既有直接导出/复制成稿保留。

目标流程：读取当前已确认内容→AI提出小红书标题、正文、按内容拆分的图片页→用户预览并采纳→编辑/保存/导出同一份成稿。语义拆页与正文重写归 AI，代码只验证页 ID、类型、范围、版本和布局安全；不按字数截长文冒充语义重组。页面应可选择合适的既有视觉风格，不强制所有内容为黑底长文本，保留原草稿与可编辑性。

先核现有候选生成、分页、NoteRelay 编辑预览与保存链路，再在本 SPEC 落准最小兼容合同。真实用户内容只读取或产生候选，不替用户采纳覆盖已有成稿；验收可使用明确标记的独立测试作品，不发布、不消耗官方失败任务。已有模型来源偏好持续有效，语义生成测试沿已验证可用来源。相关公共调用链、候选采纳边界、预览与导出分页一致性必须验证，不能只换颜色宣称修复。

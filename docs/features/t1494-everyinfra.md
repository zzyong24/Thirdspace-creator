# T-1494 用万有引擎替换 RedFox

用户于 2026-11-25 授权连续交付四期并直接创建 PR。需求与协议以用户提供的《EveryInfra 替换方案》及本轮公开目录核对为依据。验收使用脱敏假数据。真实 Key、付费试查与下载由用户另行手工验收。

1. 新建万有引擎设置、加密凭据和三平台查询工具。两台允许的主机由用户选择，默认全球主机。固定显示未配置、认证失败、余额不足、限流和响应异常。只传公开目录确认的请求参数。
2. 内容雷达允许用户加入具备稳定作品 ID 的结果，按工作区、平台与作品 ID 去重。小红书账号作品加入时刷新访问链接。视频号关键词结果不可加入，账号作品使用稳定的内部标识，用户提供的有效分享链接可作为原链接。加入后转写队列保持原长度。
3. 用户点击转写后即时取流，走现有抽音和本地或云端 ASR。图文跳过。视频号下载后在解密边界结束为 `CHANNELS_DECRYPT_UNSPECIFIED`，其密文不进入 ASR。项目继续通过 `projects.ensure` 接收雷达来源。
4. 设置页与新对话使用万有引擎，保留旧回执、旧凭据行和只读状态兼容。旧抖音分享链接导入、登录态取流、对标与收藏夹转写、本地素材导入及历史对话维持原链路。

上线前迁移在锁内查重。有重复时整个迁移失败，保留原数据。历史 Drizzle 谱系冻结，统一收敛后的迁移覆盖这些升级路径。原生网页与图文条目同表，保留其兼容性。只有抖音旧视频使用浏览器取流。

核对目录见 [抖音](https://api.everyinfra.com/api/v1/social/catalog?platform=douyin)、[小红书](https://api.everyinfra.com/api/v1/social/catalog?platform=xiaohongshu) 和 [视频号](https://api.everyinfra.com/api/v1/social/catalog?platform=wechat_channels)。费用文案仅说明查询与取视频计费。

## 本轮验收

- 通过合同全量测试、设置与雷达组件测试、后端及 Worker 聚焦回归。脱敏假数据经过实际 Worker、PGlite 和模拟 ASR，确认抖音和小红书逐字稿写回，视频号下载后以指定错误结束，图文跳过。
- Chrome 隔离实例通过设置保存、刷新读回、移除，以及桌面和窄屏检查。四个包的类型检查与超时策略通过，架构边界无新增违规。
- 独立复核补齐了重复加入后项目入口读取最新链接，以及转写队列遇到暂时读错仍持续查询的回归。全局快速对账仍报告原始 main 已有的 T-1434 收据哈希漂移。

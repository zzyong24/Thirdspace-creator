# T-1262 磁盘盘点和历史产物清理

用户2026-10-13要求查看历史安装包或其它可清理内容。先只读检查实际占用、时间与当前用途，再清理明确可再生成或有现成替代的历史安装/构建产物。保当前安装App、最新签名交付、T1246/T1261在用开发包与验证源、源码/Git/未提交改动、用户数据库/媒体/授权/密钥和其它聊天工作树。对无法证明可替代或仍在用的内容仅报告，不删除。

这是运维清理，不变更产品、服务合同、UI或数据归属；不用实现TDD/frontend/contract/e2e/reconcile大套件。验收为删除前精确路径/体积/用途及保留副本证据、删除后文件不存在、保留项存在、df实际空闲变化。清单只写本机，不提交其它用户目录内容。

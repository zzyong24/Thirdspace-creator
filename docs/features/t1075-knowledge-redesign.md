# T-1075 知识库调研与重新设计

用户2026-10-09：“知识库我想重新设计一下，我有点看不懂目前这个知识库怎么用。你找找别人的知识库是怎么做的，或者找个开源项目我们学习一下。”

## 本轮交付范围

先盘点现有页面、tokens、组件与真实能力，保留基线；调研官方产品文档/开源仓库，比较收集、整理、阅读、问答、创作引用链路。交付中文研究报告和可视化方案对比，讲清楚存什么、去哪找、怎么用到写稿。候选统一现有CreatorOS主题，不重做全局导航。任何假数据只用于独立设计候选，明确不代表用户已有资料或已实现功能。

## 决策边界

用户已授权调研和重新设计；具体信息架构、课程位置和AI整理流程待看到候选后选择。未选定候选不声称设计确认，不改生产知识库、数据归属、数据库、模型与索引体系，不clone执行外部仓库或安装新服务。正式实现范围与契约另在本SPEC确认后细化并独立审核，保留全部历史知识和来源引用。

## 验收

官方来源可核查；把已有能力与建议能力分开；方案有大白话和图；存量基线与有效差异的代表性候选同屏比较；实际渲染与目标视口检查如实记证据。本轮研究完成与未来业务实现状态分开记录。

# CreatorOS 封面与小红书图文双模板库样例

本包包含12张本轮原创AI图片：6张单封面、6张展示三页方向的图文风格预览板，以及对应简体中文模板配置。

图文预览板不是可直接上传的独立正文图片。所有样图中的标题、产品、地点、日期和使用体验只作示意，生成本期作品时换成用户自己的真实内容。公共包不含私人真人照片或候选。

按行业分类与真人/实拍/图解/AI维度筛选；12类行业方向已在SPEC定义，图片库如无样例显示空态，不伪造覆盖数量。

本机预览：在此目录运行`python3 -m http.server 43321 --bind 127.0.0.1`，打开`http://127.0.0.1:43321/`。当前目录的HTML是可交互方案预览，收藏仅保存到本浏览器，不是CreatorOS已接入功能。模型生成和项目采纳须经正式契约接入。

详细集成方案在上级`t1021-cover-template-library.md`，调研来源见`research.md`。当前独立评审已通过，保存范围和契约/数据归属仍待用户确认，生产代码未改动。

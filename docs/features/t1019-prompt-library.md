# T-1019 创作者提示词保存与复用

> 待 T-1018 用户审核及独立 SPEC 评审；本文件是实施规格，不代表已交付。实施前需将 `codex/creator-canvas` 的 T-993/T-995 代码纳入目标分支。

## 用户结果与入口

在图片/视频画布的生成描述旁提供“保存到提示词库”，并在创作入口统一打开“我的提示词”。创作者能把本次好用的描述保存、命名、搜索、插回画布或其他创作输入，看到版本与实际使用记录。画布的自动保存只保护当前画布内容，不替代可复用的提示词库。

```mermaid
flowchart LR
 A[画布生成描述] --> B[保存到提示词库]
 B --> C[账号内 PromptAsset]
 C --> D[不可变版本]
 D --> E[插入另一画布/创作输入]
 E --> F[生成任务冻结实际文本与版本]
```

## 数据与合同

- `PromptAsset(id,userId,accountId,title,kind,description?,tags,projectId?,archivedAt,createdAt,updatedAt,currentVersion)`；`kind` 表示图像/视频/文章/通用的用途，不决定模型能力。
- `PromptVersion(id,assetId,number,body,createdAt,sourceCanvasId?,sourceNodeId?,parentVersionId?)` 不可变；`PromptUsage(taskId,assetId?,versionId?,effectiveTextDigest,usedAt)` 记录引用血缘。完整的 `effectiveText` 在生成提交时作为不可变任务输入快照由既有 AI 任务服务按 `userId + accountId + taskId` 持久化并回读，不能只留 digest；对外上报只允许投影任务类型/错误码，不能投影文本。用户可编辑副本，新版不改旧任务输入。可选关联项目必须同账号，项目移除不删除提示词。
- 合同操作：列表/搜索/单条与版本读取、从现有节点保存、显式建新版/另存、归档/恢复、向节点插入。写操作后端重新读取账号、项目、画布和 revision；CAS 冲突给出保留当前输入的可恢复提示。
- 账号私有且默认本机保存；不进入 T-1017 自动上报。系统 `skill_config_overrides` 为产品级配置，不暴露给创作者提示词 API；Agent 可提出候选提示词，用户采纳后才入库。

## 交互与恢复

“保存”弹层预览将保存的**完整文本**、名称、用途及可选项目；空文本禁用并说明原因。已收藏节点编辑后显示“当前版本已变化”，提供“保存新版/另存一份”，不暗中覆盖。库列表显示标题、用途、最近修改和项目归属，可全文搜索及预览历史；“插入”只替换当前输入，不自动调用收费模型。归档后已有画布与生成历史仍能回读版本。账号切换时关闭旧弹层和在途结果，不能把旧账号文本存入新账号。

## 验收

同账号 A 保存、刷新、搜索、跨画布插入、更新/另存、历史回读、归档/恢复均读到正确版本；账号 B 列表和直链均 404。保存与生成并发时生成任务使用提交瞬间冻结文本；节点 CAS 冲突不丢正在编辑的描述。提示词正文不出现在诊断/创作上报体；旧画布无库记录仍可加载。Mac/Windows 安装包中真实操作入口有效，无假按钮。前端、合同、后端归属与 E2E 覆盖。

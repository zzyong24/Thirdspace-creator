# T-1025 创作资产、跨平台数据与上报的整体验收

> 待 T-1018 用户审核；依赖 T-1019—T-1024 完成。此任务负责完整公共调用链与真实安装包，不以孤立 helper 或模拟模型用例替代交付。

## 验收矩阵

| 场景 | 必须留下的证据 |
| --- | --- |
| 提示词 | 画布生成描述保存、跨画布复用、版本回读、账号隔离、生成任务冻结的文本与版本一致；旧画布能读 |
| 小红书 | 两真实授权账号的扫码、身份、全量分页、账号/作品指标、粉丝、错号拒收和重启恢复；与官网抽样对照 |
| 快手 | 实际取得的授权 scope、账号身份、目录与可用指标对照；不可用能力有明确状态，不能以模拟值冒充 |
| 公众号 | 通用方法与月明品牌层分离、候选采纳、文章/视觉清单版本；本机预览可用且无草稿/群发假入口，确认没有意外调用发布 API |
| 上报 | 默认零出站、两项授权组合、逐账号、粉丝/作品白名单、断网重试、撤销删除、跨渠道权限、服务器运营面板和告警 |
| 旧链 | 抖音/B站/视频号及已有项目/素材/生成/渲染/发布可继续完成；上传失败不阻断本机关键链 |
| 安装 | Mac 与 Windows 实包启动、升级、浏览器档案迁移、账号隔离、资源/Skill 包完整及回退路径 |

每个场景保留所用版本、账号别名、请求/任务 ID、时间、状态和可审计回执；真实隐私数据脱敏保存。平台采集与模型任务只在用户授权的真实账号/现有模型配置下测试；缺授权或权限记为待验证，不补拍 PASS。测试发现的阻断和范围内回归当场修复，范围外旧红项以既有任务与证据登记。最后运行本任务要求的 TDD、合同、frontend、E2E、边界、orphan 与 reconcile；只在实际通过或明确接受风险后按 taskctl 完成。

# T-1464 隐藏视频制作，保留脚本、文章、图文与复盘

## 用户确认与边界

用户2026-11-11确认T-1463两份预览及文章/图文入口“没什么异常了”，并明确要求：“把我们系统制作视频的功能隐藏吧……只支持脚本、文章、图文、复盘”。本任务是产品入口收敛，采用现有组件、样式与数据owner，不删除视频后端能力、数据或历史任务，不取消已提交任务，不重写冻结工具定义，不重签历史回执。旧正式打包冻结已结束；本次先独立审查规格，再实现和验证，随后按既有双平台正式交付及本机安装授权更新安装版；不创建tag/Release、公开分发或生产放量。

## 确认需求与结果

- FR-1464-1：系统正常创作界面只提供脚本、文章、图文、复盘这四类工作面，不显示“制作视频”导航。文章/图文入口继续按已有作品真实归属与空状态工作，不因隐藏视频而自动创建文章或图文作品。旧production阶段的“继续创作”链接回原项目脚本。
- FR-1464-2：新建作品、快速创作、项目内新增作品、联合创作成员选择不再展示或默认选中视频。新建默认文章，图文仍可选；视频来源仍作为来源资料传入原转写/项目准备流程，不把来源类型video误当制作形式video。未显示形式选择的脚本项目仍保留原项目脚本路径，不偷偷预约视频。历史未决预约/原请求保留，不把本次新默认应用到已经冻结的请求。
- FR-1464-3：编导、素材和创作入口不显示“生成视频素材”“编排视频”“配音/渲染视频”等视频制作快捷操作或推荐，保留文章/图文所需图片、封面与文本能力。历史对话与任务结果照常显示真实历史，不清空或篡改。后台视频API、手工CLI能力及原任务协议不删除，本次不引入新禁用契约或改变已提交任务执行；用户手动明确要求已隐藏能力不属于新的界面入口。
- FR-1464-4：旧`/projects/:id/production`及`/projects/:id/outputs/:outputId/video`入口在原账号组、项目/作品归属核验后回到对应项目脚本，不挂载制作工作台，不在SSR读路径get-or-create制作状态。跨组/跨项目不能通过跳转暴露作品存在或绕过原守卫。已有视频作品、脚本、素材、成片、发布和复盘数据保留；支持读取历史记录的后端契约保持。已有作品的常规导航不再引流到视频制作。
- FR-1464-5：视频号绑定、视频来源采集、视频/音频转写、原素材管理、已发布作品指标及复盘正常保留；这些不是视频制作。无需删除供应商密钥、模型配置或历史文件。设置中的历史视频模型信息不作为删除对象；若入口仍指向制作工作台则收起该入口。

## 已核实入口

`project-workspaces.ts`含制作视频tab；`project-href.ts`把production继续链接导向制作页；`work-type-fields.tsx`、`new-project-form.tsx`、`project-output-home.tsx`把video作为默认或可选形式；`quick-create-work.tsx`由视频来源选择video；`work-composition-workbench.tsx`提供视频成员；两个video/production页面真实挂载制作台；编导快捷动作仍有生成视频素材。实施前继续检索公共快捷指令与素材入口，按同一需求移除实际入口，不扩大为后端删除或视频数据迁移。

实施约束：`WORK_CHOICES`同时被创建会话用于冻结顺序、未知回执恢复和已有结果快照，不能直接删除其video成员后让历史原请求少建或丢失结果；展示选项与新默认值单独收敛为文章/图文，保留原协议枚举和原创建session。编导快捷动作当前源在`frontend/src/fixtures/selectors/copilot.ts`，虽位于fixtures目录但被真实页面消费，不把它误当无关假数据。新任务不修改后台工具schema或执行白名单；只收起实际UI入口与推荐，历史工具执行与API兼容保留。

## 验收

- AC-1464-1：旧无作品项目、多形式项目、只有历史视频的项目、作品读取失败以及production深链状态，顶部均无制作视频tab，脚本/文章/图文/复盘合法导航不回退或误绑作品。
- AC-1464-2：新建、快速来源创作、项目内新增及联合成员选择没有视频选项，新提交不含video；视频来源ID/类型仍保留，默认文章与图片可正常创建。原冻结请求恢复不重新预约、不更换幂等键。
- AC-1464-3：编导与素材的当前快捷按钮/推荐中无视频生成或制作入口；图片/封面/文本操作仍是真实操作，历史结果仍展示原真值。
- AC-1464-4：已归属的旧视频制作链接安全返回原脚本；跨组/跨项目仍拒绝。跳转不调用生产状态创建/生成/渲染/写库端口，不删除已有作品。
- AC-1464-5：T-1463联合候选/预览/保存守卫、稿件准备、原视频转写及文章/图文主要前端回归通过，前后端类型/边界及LED-047、LED-053相关门按实际触达执行。不为隐藏低影响按钮编写镜像单测；重点测试真实创建参数、跳转副作用、归属与旧请求恢复。
- AC-1464-6：代码提交后重新冻结，正式双端包使用同一候选，验证安装包签名/公证/Windows安装启动卸载；本机先退出卸载旧app再安装，不清理用户数据。原项目当前脚本、两作品版本及待采纳候选保持。安装版入口可见性做真实核对，OS自动点击限制如仍存在则复用用户人工验收，不冒充机器通过。

风险和停止条件：旧数据与冻结请求属于不可迁移边界；无法证明归属时不跳转到猜测项目；需要改后端执行/工具版本或删除数据时超出本次展示收敛，先记录范围调整，不隐式扩展。磁盘预算沿用顺序安装与实测展开空间，不创建同盘旧app副本。仅使用本次任务生成且可验证的新/旧安装产物回收策略，历史日志和用户数据不清理。

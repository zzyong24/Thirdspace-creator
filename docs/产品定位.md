# CreatorOS 产品定位(宪法 · 单一真值)

> **这是宪法。** 所有 SPEC 审核对照本文件判"是否合定位"。它合并了 [PRD v0.1](prd/project-workflow-prd-v0.1.md) 与 2026-06 的产品演进(编导对话化 / 飞轮 / 数据底座 / 横竖屏)。定稿 2026-06-30。演进时改这一份,不另起散文档。

## 1. 一句话定位

**一个编导式的自媒体内容生产系统** —— 不是项目管理工具,而是一个**越用越准的「编导智能体」**:它替创作者出选题、起草文案与结构、管素材,发布后采集真实表现回流校准,让下一条内容更准。

## 2. 目标用户

中文自媒体内容创作者(以观点视频 / 口播 / 短视频为主),个人或小团队,持续产出、在意数据、想把"靠感觉"变成"有方法"。

## 3. 核心价值 / 护城河:飞轮复利

> **盲预测 → 发布 → 采集真实表现 → 对照偏差 → 沉淀经验 → 回流让下一条更准。**

护城河是**"越用越准"**:用得越久,系统越懂这个创作者什么内容会爆、什么开头有效。数据是别人拿不走的资产。

## 4. 生产流水线(项目主干,2026-07-03 修正案:两阶段)

**脚本(稿面:选题/脚本/素材/发布动作一体)→ 复盘(数据对照/经验沉淀)。**研究/策划/制作不再是独立阶段(职能由稿面的选题卡、弹药区承载);发布是稿面上的动作(盲预测/登记已发布)而非阶段。未来 agent 具备录制/生成能力时可扩展「拍摄/生成」阶段。详规:[two-stage-project](superpowers/specs/2026-07-03-two-stage-project-design.md)。(原「七步流水线」表述存档于 git 历史。)

## 5. 核心原则(不可违背)

1. **每个项目必须有 Brief。**
2. **每个阶段必须有明确交付物;前一阶段产物自动流入下一阶段**(SEAM 接缝)。
3. **AI 只产候选,人确认关键产物**(确认门:AI 不直接写领域实体)。
4. **复盘必须反向沉淀经验**回流到选题/定位/校准,而不只看数据。
5. **人出判断与品味,AI 出草稿、苦力、学习** —— 产品是"编导"不是"表单填写机":能 AI 干的让 AI 干、人只审/改/删。

## 6. 编导对话化(ChatBox)

AI 功能(选题/校准/预测…)本质多轮对话,统一成一个**上下文感知的 ChatBox**(进化现有 Copilot):按当前页面/按钮**注入对应 skill + 提示词 + 真实数据底座**;AI 功能工具化,结果渲进对话、走采纳门。**每轮输出被 Zod schema 约束**(防发散)。

## 7. 数据底座(真实创作历史)

创作者**真实已发布作品 + 播放/评论 + 创作链**导入为**历史项目**(`source:imported`),是飞轮的真实记忆 + 创作新内容的来源库。同时喂:校准复盘、选题(评论需求/爆款经验)、定位(数据反推)、知识库(可复用 Hook/金句)、首页驾驶舱。**替换所有 mock/seed。**

## 8. 产品边界(明确不做)

- **不做视频编辑器**:只产"文案 + 结构 + 管素材",不管用户怎么剪(预览播放/导出渲染/时间线 = 不做或诚实标规划中)。
- **不分视频类型**:唯一的"类型"区分是**横屏 / 竖屏**;平台只在发布层选,不在项目层。
- **变现中心:移除**(太重、不影响飞轮)。

## 9. 架构铁律

1. **全程 Vercel AI SDK**(`modelFor` 按 capability 选模型,可切换不同模型)—— 不用 Claude Agent SDK / 旧 LlmCompleter。
2. **AI 只产候选,经 confirm 门由 backend service 物化**;AI 不直接写领域实体。
3. **提示词 / 工具 / 输出 schema 三者可注入、可配置**(Skill 三位一体 + JSON Schema 配置口子)。
4. **每轮 AI 输出被 schema 约束**(Vercel `generateObject`/`streamObject` 校验+重试)。
5. **不造轮子**:做之前先调研 OSS / 仓内已有实现(如抖音采集抄 cheat-on-content 的 launchPersistentContext)。

## 10.5 信息架构(§11 修正案 —— **已撤回**,2026-07-03 用户复验裁决)

>
> 原文:一级导航固定为**今日台 / 作品 / 库 / 设置**四项 + 全局编导对话(⌘K / 稿面常驻)。任何新能力先问三个归属:是「行动」(进今日台队列)、「工作面」(进作品生命周期或库 tab)、还是「配置」(进设置页签)——**禁止新增部门式一级中心**。页面存在的理由是「干」,只读仪表信息并入所属工作面,不单独立页。详规:[first-principles-redesign](superpowers/specs/2026-07-03-first-principles-redesign.md)。

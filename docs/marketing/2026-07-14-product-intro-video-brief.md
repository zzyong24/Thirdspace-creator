## 1️⃣ 这是什么?解决什么问题?

### 1.1 产品是什么(你用截图快速呈现)

**核心信息(一句话定位):**
> **CreatorOS —— 一个「编导式」的自媒体内容生产系统。它不是项目管理工具,而是一个越用越准的「编导智能体」。**

**它替你干的四件事(截图配文点):**
- **出选题** —— 从你的真实数据 + 热点里推选题,按预测分排序
- **起草文案与结构** —— 结合 Brief 与真实素材直接起草脚本,AI 出草稿你只审改
- **管素材** —— 本地素材库,视频/图片/字幕,能预览能播
- **回流校准** —— 发布后采集真实播放/评论,对照你的预测,沉淀经验

**九大模块(截图逐张,一句话带过):**
| 截图 | 一句话配文 |
|---|---|
| 首页驾驶舱 | 播放/点赞/粉丝/完播率总览 + 继续创作 + 待办 + 热门选题 |
| 定位中心 | 账号定位是宪法,用数据反推、持续演进 |
| 选题池 | 每日出题 + 黑马雷达 + 收藏夹跟拍,按契合度排序 |
| 稿面工作台 | 选题→立论→脚本→素材→盲预测,一屏搞定 |
| 素材中心 | 本地素材库,视频真首帧、能播、真时长 |
| 视频制作 | 横/竖版、口播进框、富动画、成片预览 |
| 复盘 | 盲预测 vs 真实数据,偏差 → 经验 |

**记忆点(反复强调的一句):**
> 「能 AI 干的让 AI 干,人只审、改、删。产品是**编导**,不是**表单填写机**。」

**画面·动画建议:** 九宫格模块图依次点亮;或一条"选题→写稿→制作→发布→复盘"的流水线动画,每站高亮对应界面。

## 2️⃣ 为什么要做这个产品?(精简口播 + 真实证据配图)

> 这段的**口播要精简**(45–60 秒);但底下的"真实证据"用**图**呈现(见文末配图提示词),让观众看见你**真的走过 skill 这条路、真的踩到头了**,不是空喊。

**口播主线(精简版,三句话):**
> 「我想把自媒体创作**系统化** —— 定位 → 选题 → 写稿 → 制作 → 分发,一条线走完。
> 为了这个,过去一年我自研了几十个 skill、还接了 Agent 协作平台。能力堆够了,但**用起来还是乱**。
> 我才想明白:**skill 是「能力」,不是「系统」。工具给你能力,系统给你秩序。**」

---

**真实证据(不是空谈,全是我亲历,建议做成 3 张图轮播):**

**证据一 · 我以前是这么做视频的:一条 13 个 Agent 的 Multica 创作管线。**
配图、写稿、配音、审查、剪辑、分发——**13 个 Agent 一条龙**(基于开源 Agent 协作平台 Multica)。听着很牛,可真用起来:
- **依赖靠手工设,设错一个 ID,下游就一直 blocked**;
- 光这条管线我就写了**整整四版「修正」**,还得让审查者**每分钟 Loop 扫一遍状态**才不乱;
- 可视化的 Canvas 和真正的执行**是两张皮**;
- 一堆 Agent **互相打架、没人拍板**:好几个都说自己能干、还互相甩锅,信谁?没有仲裁。
> 我的实战结论:「Multica **不是银弹**……它给了协作的壳,但**内容质量、顺序、仲裁,仍然要人兜底。**」
> —— 出自我知识库《短视频创作管线》(source: multica-pipeline)+《Multica 实战》

**证据二 · 单个 skill,我反复打补丁打了四次(v2 → v5)。**
就拿我的 `creative-video-workflow`(做知识视频的全流程 skill):
- v2:PPT / Excalidraw / Remotion **三套视觉语言不一致,乱**
- v3:加一个 `scenes.json` 契约治视觉漂移
- v4:改用**「信息稿」当唯一真源**、把渲染拆成独立工程
- v5:再加 **G1–G5 五道强制质量门 + 每条必写复盘**
**每一版都在给一个越长越复杂的单体 skill 打补丁 —— 当一个 skill 复杂到要自带门卫和状态机,它其实已经在喊「我需要一个系统」了。**

**证据三 · 同一个 bug,我在 v3 / v4 / v5 踩了三次。**
> 我的复盘原话:「不要给长内容加 lazy-load / reveal,**v3 v4 v5 三个版本都踩过同一个坑**。」经验只写在 console log 里,**下次会话我自己都读不到。**
没有沉淀系统,每一版都是第一次。

---

**收口(把上面收成一句洞察):**
> 「单个 skill 补不上、单个 Agent 平台也补不上的,是**版本治理 + 质量把关 + 经验沉淀 + 流程门控**这四件事。
> 我需要的不是更多能力,是一个把这些能力**组织起来、管起来、复盘起来**的系统。**CreatorOS 就是我给自己造的那个系统。**」

**可提炼口播金句:**

- 「一个 skill 复杂到要自带门卫,它就是在喊'我需要一个系统'。」
- 「没有沉淀系统,每一版都是第一次。」
- 「工具给你能力,系统给你秩序。」

## 3️⃣ 产品系统演示(录屏,0→1 全流程,占篇幅最大)

> 这段是**录屏 + 讲解**。下面是**演示脚本**:每一步给"操作 / 屏上重点 / 讲什么"。串起来就是一条完整的 0→1。

### Step 0 · 账号导入(飞轮的起点)
- **操作**:设置 → 绑定抖音账号(扫码登录)→ 导入历史作品
- **屏上重点**:真实作品、播放/评论被拉进来,变成"历史项目"
- **讲什么**:「一切从你的**真实数据**开始。你过去发过什么、哪条爆了、评论在问什么——这些是别人拿不走的资产,也是这个系统'越用越准'的燃料。」

### Step 1 · 多账号管理
- **操作**:左下角切换当前抖音号(如"月明水清深")
- **屏上重点**:多个账号各自独立的数据 / 定位 / 选题池
- **讲什么**:「一个人可能运营多个号。每个号的定位、数据、选题池都是隔离的,互不串台。」

### Step 2 · 项目呈现(两阶段)
- **操作**:进"项目",看项目列表(含导入的历史项目)
- **屏上重点**:项目 = 脚本(稿面)→ 复盘 两阶段;进度、状态
- **讲什么**:「每一条内容是一个项目,只有两个阶段:**把它写出来(稿面),把它复盘掉(数据沉淀)**。研究、策划、制作都收进稿面,不再是一堆并列的表单。」

### Step 3 · 定位确认(宪法)
- **操作**:进"定位中心",看/确认账号定位
- **屏上重点**:定位是单一真值;可用数据反推、演进
- **讲什么**:「定位是这个号的'宪法'。后面所有选题、写稿、打分,都对着它判'合不合适'。它不是拍脑袋填的,是能用你的真实数据反推出来的。」

### Step 4 · 选题推荐
- **操作**:进"选题",看选题池;每日出题 / 黑马雷达抓一批
- **屏上重点**:选题按预测分 / 契合度排序;热度、来源(热点/对标/需求)
- **讲什么**:「选题不靠灵感枯竭时硬憋。系统每天出题、扫黑马、盯你收藏的对标,按'跟你定位有多契合、预测能不能爆'排好给你挑。」

### Step 5 · 项目制作(稿面 → 视频)
- **操作**:选一条选题立项 → 进稿面 → 准备素材 → 起草脚本 → 制作视频
- **屏上重点**:
  - 稿面:编导结合项目 Brief 与真实素材直接起草脚本(有叙事纪律,不是编的)
  - 制作:上传口播粗剪 + SRT + B-roll 素材 → AI 分场决策
- **讲什么**:「写稿不是让 AI 瞎编。它先接地——用你的真实素材、真实场景开场,前因后果不跳步。制作时,你的口播 + 素材进来,AI 决定分几场、哪句配什么信息卡、哪里插空镜。」

### Step 6 · 视频导出(成片)
- **操作**:AI 分场决策 → 确认 → 渲染 → 成片框内预览
- **屏上重点**:横/竖版、口播人脸在框里、富动画(数字递增/对比条/进度式)、双语字幕、成片能播
- **讲什么**:「一键渲染出成片:横版竖版都支持,口播完整不裁脸,动画不是干巴巴的淡入,是'长出来'的。渲染完直接在框里预览。」

### Step 7 · 闭环(可选,点到为止)
- **操作**:发布登记 + 盲预测 → (未来)复盘对照
- **讲什么**:「发之前先盲预测,发之后采真实数据对照。**预测准不准、哪里差了,变成经验回流,让下一条更准。**这就是飞轮。」

**画面·动画建议:** 全程录屏为主;关键转场用流水线动画标"现在到哪一步了"(定位→选题→写稿→制作→导出),让观众始终知道在全流程的哪一环。

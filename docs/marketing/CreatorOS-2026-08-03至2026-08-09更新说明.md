# CreatorOS 2026.08.03—2026.08.09 更新说明

> 统计时间：2026-08-03 00:00—2026-08-09（America/Los_Angeles）。
> 统计口径：仅计入 `orchestrator/events.ndjson` 中由 `taskctl` 记录为 `complete` 的任务；进行中、待办和仅有聊天描述的事项不算已更新。

## 一句话总览

本轮重点不是堆新入口，而是把 CreatorOS 的写稿、桌面打包、渠道模型、白标交付和项目数据链路做得更稳、更可解释：原稿可保真进入候选，Copilot 本地文件读取不再重试风暴，Windows 恢复轻量正式打包链，渠道配置同步与签名链更完整，重复项目可自动收敛且不删除用户数据。

- 功能、交付、安全或稳定性闭环：23 项。
- 调研或只读诊断：6 项。
- CreatorOS 仓库同期提交：26 个。

- 当前产品版本：`0.3.0`。

## 六组用户可感知更新

### 1. 写稿更可靠

- T-680：选题卡、项目页和 Copilot 的成功写稿统一进入可预览、可编辑、可采纳的脚本候选；时长改为自然目标区间，不再靠重复或灌字数硬凑；已有有效正文时保留结果并给质量提醒。
- T-727：用户明确要求“原文不改”时，完整原稿以可审计引用恢复并生成保真候选，不再被选题卡、定位或创作建议擅自改写；仍保留“候选→用户采纳→落稿”的确认边界。

### 2. 桌面端与制作更稳定

- T-673：Copilot 读取本地文件后能稳定配对工具结果并继续回答；坏历史调用只失败一次，不再自动续跑形成请求和日志风暴。
- T-675：Windows 默认正式流水线恢复少文件 production closure，不再把完整开发依赖树塞进安装包；真实安装、首启和卸载验证通过。
- T-689：前端、Tauri、Rust 与产物版本统一为 `0.3.0`；macOS 本地测试 DMG 与 Windows 安装包均完成构建验证。
- T-710：B-roll 的常见中文、大小写、空格、连字符和同义词输出会先归一化；单个可修复异常不再拖垮整批画面匹配。
- T-711：包含 B-roll 容错修复的 macOS `0.3.0` 本地测试包完成真启动与 DMG 校验。

### 3. 渠道模型闭环更完整

- T-697/T-698：Growth 渠道配置建立 Ed25519 签名信任链并完成生产部署；CreatorOS 使用公开信任材料验签，私钥不进入仓库。
- T-701：激活成功但缺少渠道身份时，不再静默表现为“模型没生效”；设置页显示明确原因并提供重新校验入口。
- T-704：桌面壳和设置页触发的零字节配置同步请求不再被误判为非法请求；真实非空请求仍失败关闭。
- T-706：正式桌面包在未显式注入授权 origin 时复用受信任官方默认地址，避免误报“授权服务尚未配置”；非法自定义地址仍被拒绝。

### 4. 创作体验更顺

- T-681：定位前采中的多选答案、补充文本和联网搜索词按账号与会话保存在本机，切页、刷新或重启后可以继续；本机草稿不会覆盖已提交的正式定位。
- T-682：知识页默认进入“知识库”，IP 课程调整为第二个 Tab；显式课程深链、刷新和返回仍保持兼容。

### 5. 项目数据更清楚

- T-724：自动化导入作品后再补登记到既有创作项目时，系统会收敛为唯一可解释的作品归属；被替代的 imported 投影只做可逆归档，不删除用户项目或媒体数据。

### 6. 白标与换码更安全

- T-717：完成“智溯AI”Growth 渠道配置和独立 macOS 本地白标测试包，完成包身份、图标、唯一安装与真实启动验证。
- T-722：渠道包在尚未选择模型时也能读取内置技能清单，正常 CreatorOS 包行为保持不变。
- T-699/T-700/T-728：仅重置本机激活状态的能力扩展为项目 Skill，并支持受锁定渠道包；精确清除激活相关状态，同时保留项目、定位、账号、知识库、素材、数据库、日志、机器身份和主密钥。

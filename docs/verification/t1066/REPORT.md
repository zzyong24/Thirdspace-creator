# 全系统超时整改交付

本轮源码已覆盖T-1065原222条控制/默认/声明，逐条调整或登记保留理由，并修复额外发现的SDK默认。单次正执行最短两分钟；普通/自主持久任务新默认30分钟；转录准备端口跟随原任务剩余期限。有限观察结束后保留原ID与真实运行状态，可继续查询，不重发任务。

此前本机1.2.0最新失败约31.044秒；固定30秒宿主等待确实可复现中止合法素材准备。原始日志未保留完整原生AbortError栈，不能把未观察到的内部抛错位置写成确定事实。诊断详情见../t1064-aborterror-diagnosis.md。

```mermaid

 A[新任务首次固定期限\n普通默认30分钟] --> B[转录准备、登录、重试、抽音\n继承同一原期限]
 B --> C[真实成功、失败或用户取消]
 A --> D[页面或CLI观察]
 D --> E[等候结束保留原任务ID\n继续查询、不重新提交]

```

独立外层必须覆盖内层完整时间，包括串行尝试、退避、排队、冷启动及清理余量。例如浏览器两次180秒启动由370秒外层覆盖。共享原绝对deadline向内传播时，不会重新开启两分钟；历史期限已过仍然停止。TTL、媒体时长、心跳/轮询间隔与取消后的强杀宽限没有被改成两分钟。

## 渲染依赖补漏

HyperFrames0.7.54内部短执行等待、动态配置/CLI及12处Puppeteer页面默认，第一方环境变量不能全部覆盖。本轮在同版本持久pnpm补丁中补齐，保留秒单位86400上界、明确0禁用、授权TTL原余量和两处取消后500ms强杀。CDP内层与外层按预算+10秒计算并清理timer，正常关闭外层覆盖原protocolTimeout，不能用120秒包住300秒。帮助文字也与新默认一致。

patch-commit后离线、禁止安装脚本、frozen-lockfile安装真实应用成功，锁文件只保留补丁关联变化。门卫检查实际包版本/补丁哈希/已应用CLI哈希；升级必须复审内部消费者。独立复核结果见[implementation-review.json](implementation-review.json)。它是静态和语法审查，行为证据如下。

## 用户旅程

```mermaid
flowchart LR
  A[作品的创作素材] --> B[只看本作品画布]
  B --> C[生成图片 / 生成视频 / 选素材]
  C --> D[在画布比较]
  D --> E[明确保留或加入作品]
  E --> F[返回作品]
```

## 已实现与核验

| 场景 | 结果 | 证据 |
| --- | --- | --- |
| 作品“创作素材”直接进入画布 | 通过 | E2E 从作品页进入，只显示本作品画布；新建自动关联，能查看账号全部画布 |
| 首次进入明确下一步 | 通过 | 图片、视频、已有素材三项入口；显示当前作品归属及结果去向 |
| 当前账号素材选择 | 通过 | 图片与视频真实文件预览、插入、刷新恢复；抽屉搜索/类型筛选限定已加载素材，并有加载更多和无素材上传入口 |
| 画布操作 | 通过 | 节点、连线、撤销重做、滚动平移、组合键缩放、文本框内部滚动、旧文档兼容 |
| 保存与导航 | 通过 | 改标题立即返回先保存；CAS 版本冲突时留在画布并提示重载 |
| 窄桌面 | 通过 | 1024×768 下主要操作可见并可点击；截图核对无遮挡 |
| 账号隔离 | 通过 | 切换账号后画布库和直链均不泄露原账号资源 |
| 模型不可用 | 通过 | 生成按钮禁用并显示原因/设置入口；没有假提交 |
| 结果保留与加入作品 | 通过（模拟任务回执） | 浏览器中确认一次、首次关联失败提示、重试只关联一次，目标作品真实落库；任务本身由测试模拟 |

生成结果旁增加“放到画布 / 保留到素材库 / 加入当前作品”；操作以同一历史记录的 `taskId + assetId + inputRevision` 对应。历史按服务端时间排序，展示模式、时间、版本与用户可理解的状态，任务 ID 收进详情。加入作品前先确认真实任务，项目关联失败时保留确认状态供单独重试。上述**结果操作的真实模型全链仍待 T-993 安装版验收**；本轮隔离环境没有安装版供应商密钥，不能把界面代码检查或服务测试写成真实生图/生视频通过。

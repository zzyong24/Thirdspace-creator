# T-1019 成功候选确认入口回归

## 用户能看到什么

内容雷达生成了改写初稿后，可以点击“确认写入选题池”。生成仍在进行时，不显示确认入口；初稿还没有正文时，入口显示为禁用态。已有候选的归属、来源和幂等校验仍由原确认接口处理。

```mermaid
flowchart LR
  A[生成中] -->|完成| B[已有改写初稿]
  B --> C[确认写入选题池]
  C --> D[原确认接口校验并保存]
  A -->|暂无正文| E[确认入口禁用]
```

v2 · 写你的口播稿——保存即新版本,可回滚

我整理工作笔记时，先把问题写清楚，再写尝试过的做法，最后记录观察到的现象。没有实际观察的内容就留空，不为了完整而补成一个结论。


我想留给自己一张四行练习卡。以下四行属于正文，请保留原来的文字、顺序、换行和每处六个下划线，让读者以后自己填写：


问题：______

尝试：______

观察：______

下一步：______


空白不是结果，只是提醒我把事实和判断分开。这里没有统计数字，也不承诺一定提高效率。记录之后，留一个值得继续观察的问题。

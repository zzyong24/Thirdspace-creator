石墨极简风

先写问题，再记录方法

01

先写下，这次要解决什么问题

我整理笔记时，会先写清楚要解决的问题，再记下实际做过的步骤，最后检查结果。

比如整理一份阅读笔记，我会先问自己：这次阅读解决了什么疑问？接着写下试过的方法，以及还没有想明白的地方。

这个问题可以具体一点：原来哪里没理解？读完以后，哪一点有了新的认识？如果暂时还说不清楚，就把疑问先留下来。后面记录方法时，再回头看它回应的是哪个问题。

02

沿着问题，记录实际做过的步骤

问题写下来之后，再顺着实际过程记录：先做了什么，接着尝试了什么，做到哪里仍然没有想明白。

读到的方法和自己做过的步骤，可以在笔记里分清楚。只是读到了、还没有亲自尝试的方法，就注明“尚未尝试”；已经试过的，则写下实际过程。

这样回看时，能知道哪些内容来自阅读，哪些是自己的实践记录，也能把做过的步骤对应到开头的问题。

03

写完步骤，再回头检查结果

步骤记完，还要回到最初的问题：现在想明白了什么，还有什么没有想明白？

整理阅读笔记时，可以把已经理解的部分写下来，再留下仍然困惑的地方。只想明白了一部分，就照实记录这一部分；暂时没有答案，也可以写明。

检查结果不必写得复杂。几句具体的话就够了：现在能解释什么，哪一步还说不清楚，接下来需要继续弄明白什么。

04

结束工作时，留下一个追问

我想保留一个习惯：每次结束工作，记下一个仍然值得追问的问题。

阅读笔记也可以这样收尾。从还没有想明白的地方，找出下一次想继续弄清楚的事。比如，把“这里还不太懂”写得更具体一些：“我还不能解释这一步为什么这样做。”这只是提问的示例，具体问题要来自当次阅读。

留下的问题不必当场回答。先把它写清楚，再考虑下一步。

05

下次整理笔记，试着留下这四行

这次要解决的问题：______
实际试过的方法和步骤：______
目前想明白的部分，以及还没想明白的地方：______
下次仍然值得追问的一个问题：______

这里没有统计数据，也不承诺这样记录，效率就一定提高。我想保留的，是整理笔记时写清楚问题、实际做法和当前结果，结束工作时再留下一个值得追问的问题。

## 卡住、走错与犹豫

1. **资料移动入口需探索一次**：主视图只有编辑、用到项目和更多按钮。先打开“更多资料操作”才找到文件夹下拉控件。功能真实有效，但第一次整理资料会有一次寻找入口的犹豫。
2. **切换文件夹后阅读区清空**：从全部资料切到“访谈原文”后需要再点击列表条目。资料没有丢失，但连续整理后读原文会多一次点击。
3. **原文换行合并**：采访者与受访者紧接着显示，阅读连续访谈比编辑框更费力；不会导致数据丢失。建议保持纯文本换行，或明确说明采用 Markdown 阅读规则。
4. **项目前置画幅没选时创建禁用**：项目名称和描述填好后还需选择必填画幅；发现两个画幅均未选后，选择竖屏即完成创建。这是前置表单的实际犹豫，不归为资料书架阻断。
5. **放大/390 阅读需滚动**：资料详情位于分类和列表下方，鼠标任务可继续；这不是桌面首选窗口体验。200%弹窗滚轮可到操作按钮。
6. **焦点缺口已修正**：初始关闭弹窗让键盘用户丢失原位置；已在当前服务修复后重复核验真实焦点返回，留存历史观察。

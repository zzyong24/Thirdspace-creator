## 最影响完成度的三处

**VR-01｜身份失败仍提示直接同步（中，可观察缺陷）。** 两张 `identity-required` 图在“请先扫码绑定这个账号，再同步数据”下面继续显示“尚无后台报表，可点击‘同步数据’读取当前账号数据”。用户会收到两种下一步指令。身份失败时删掉空态中的同步指令，保留“尚无后台报表”，或改为“完成账号绑定后即可同步报表”；账号、平台和错误原因必须保留。修改后检查同一状态只指向先绑定；恢复后同步是否有效需要真实操作验证。

**VR-02｜恢复动作没有成为当前主动作（中，规范内层级问题）。** 恢复按钮是红字浅描边，顶部同步仍保留实心按钮轮廓，仅变淡。有效下一步需要用户在两处动作间比较，红色按钮也容易被读成警告或危险操作。身份失败状态用现有 Button 主样式突出“扫码绑定账号”；错误说明继续使用现有语义色。同步若保留，使用清楚的不可用或次级状态并关联绑定原因。恢复后沿用正常同步样式。检查1366px和窄屏每页只有一个主动作；按钮功能、键盘与恢复结果未验证。

**VR-03｜标题尺度疑似偏离页面标题规范（低，待复核候选）。** 八张图的标题呈现约32px级视觉尺度，字面高度接近30px；390px占两行，首屏重心主要落在标题。规范要求页面标题24px。主Agent先复核实际字号，若不是24px再统一现有标题变量；若已是24px则关闭此候选。保留完整账号名称与语义换行，不更换字体或页面骨架。以相同视口检查状态和动作仍完整可读。

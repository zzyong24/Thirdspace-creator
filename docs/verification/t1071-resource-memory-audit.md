# T-1071 全系统资源与内存排查

用户2026-10-07要求检查系统资源浪费与内存泄漏，已明确“不确定，全面检查”。本轮为诊断：先定位真实资源保留或重复工作，再交付可追溯证据，不先假定高内存就是泄漏。

## 范围与边界

覆盖 CreatorOS 前端页面与长期会话、后端服务与缓存、独立 Worker 的任务/浏览器/子进程、Tauri 桌面与运行时生命周期。只读采样本机相关进程；隔离测试只使用合成输入及临时目录，不读取账号密钥，不重发真实模型/采集/生成任务，不关闭运行中进程，不清理用户数据，不修改产品运行代码或安装版。

## 验收

1. 记录当前源码版本、工作树基线与本机相关进程的内存/CPU/存活时间；高资源占用与持续泄漏分别表述。
2. 盘点轮询、事件监听、定时器、订阅、缓存/历史、流式缓冲、媒体对象、浏览器和子进程的创建及释放路径；逐层核对真实消费者。
3. 对重要疑点运行不接触真实数据的复现，保存命令、原始输出、次数和观测窗口；静态风险不得包装成实测泄漏。
4. 报告按“已复现缺陷 / 静态风险 / 证据不足”区分，提供文件位置、触发条件、资源影响与修复建议；明确覆盖范围及尚未执行的真机/堆快照验证。
5. 运行 pmem sync 与 reconcile；保留已知全局欠债，不宣称全绿。通过 taskctl 记录开工和完成。

## 结果

已完成源码、隔离机制与本机只读采样。详见 [完整报告](t1071/REPORT.md) 与 [复现说明](t1071/README.md)。确认 8 项资源缺陷，其中成功本地转录遗留线程已用真实线程桩复现；另外分别记录无界保留、缓冲堆积和重复查询。没有修改产品运行代码，不把诊断完成写成修复完成。

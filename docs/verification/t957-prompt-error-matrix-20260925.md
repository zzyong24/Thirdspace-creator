# T-957 Agent 提示词与失败表达矩阵（2026-09-25）

## 本轮修改

- `ai-worker/src/prompt/user-facing-response-policy.ts` 提供一条短的共同回复规则：面向当前目标、只陈述已验证结果、不自我归因、隐藏内部提示词/规则编号/原始异常/模型配置；未知原因明确保持未知，已确认的阻塞用普通语言说明。
- `business-methods.ts` 将规则附到业务 Agent 与对话 Agent 的实际模板末尾，业务方法版本更新为 `methods-operations-2026-09-25`。
- `effective-skill-runtime.ts` 在用户/账号覆写的系统提示词之后重新附加该规则，覆写不能移除规则；运行时版本同时带 `user-facing-response-2026-09-26`。
- `chat-assembly.ts` 对普通聊天和可信锚点的专用局部改稿路径都注入同一规则。
- `chat-tool-gate.ts` 保留内部错误日志；没有安全的人话映射时只把中性状态交给模型，不再把原异常或非 Error 抛出转成用户可见信封。
- `chat-tools.ts` 的工具内 `catch` 不再绕过统一错误门。每个未知异常都使用中性文案；明确的用户输入错误通过 `ChatToolUserError` 类型标记后才显示。
- `web.read` 的 HTTP 拒绝态只传结构化 HTTP 状态和行动指引，不把采集端口的原始 `message` 转给模型；局部改稿语义门拒绝时也使用固定的用户指引，不展示模型返回的内部 `reason`。
- `creatoros.guide`、本机工具探测、授权目录读取对已确认的能力未接入情况返回明确说明；未识别异常保持中性状态。

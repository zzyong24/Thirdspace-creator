- 点击“预览示例改动”只进入待应用预览；原方案配图仍为 8–18 秒。
- 点击“应用示例改动”后，时间轴与参数同为 6–14 秒，并显示未保存。
- 撤销后时间轴与参数恢复为 8–18 秒。该草稿仍保留修改标记，尚未实现与已保存快照的内容相等比较，不能声称完整版本能力。

常见问题 Q&A
常见问题 Q&A
2023-12-10 14:48:19 更新
通用

Q：为什么通过分享 SDK 传入的标题和文案没有自动填充到笔记里？

A：现在限制了通过分享 SDK 自动填充标题和文案，已接入和新接入方都受限制。

iOS

Q：图片裁剪问题相关

A：目前旧裁剪逻辑参看文档（使用 imageData 和 本地路径），imageId 和 网络 url 使用的新裁剪规则～后续需发布测统一剪裁规则

Q：图片为什么会保存多份？

A：图片最多可能会保存两份。

一份是分享 sdk 利用的是相册进行的资源传递，如果采用本地路径或者 imageData 进行数据传递的话，会保存在相册一份；
一份是发布测功能，在发布编辑页面有默认选项是否保存到本地，默认选中，如果选中发布成功后，会保存带有水印的图片到本地

Q：AppID 是什么？和 AppKey 有什么区别？

A：是一个东西，之前表述差异，文档上已修改～

Q：首次分享成功，后面就分享失败了（或报错 分享失败: app未注册 state: -10000001），是什么原因？

A：主要原因为 Appkey 与 bundle ID 不匹配造成的。因为用户首次分享，为了更好的用户体验，是不进行鉴权的，所以能够分享成功～

Q：跳转到小红书，取消分享，为什么不会跳转回 App？

A：目前设计如此，后续需要产品权衡迭代优化

Q：为什么分享到小红书，并没有进入到小红书 App，而是打开了 safari 中的网页？

A：check 下面文件 apple-app-site-association ，苹果认为手机没有小红书 app，所以出现这种情况。重新卸载安装/同步文件，可能解决这个问题

Q：分享到小红书后，如果未登录，在登录后，为什么iOS 和 Android 表现不一致？

A：目前双端这点存在差异，需要后续产品迭代统一

Q：为什么跳转到小红书，未进入到发布编辑页面，而是停留在相册选择页面？

A：出现这个问题的原因是未获取到相应资源或者资源下载失败。chaeck 一下资源 url 链接是否正常或者相应资源是否存在？如果都确认没有问题的话，需要找小红书 RD 排查

Q：xcode 15 编译报错

A：系统原因，添加相应一些配置，可 Google 相应报错问题，类似这种 ios - Xcode - Bundle format unrecognized, invalid, or unsuitable - Stack Overflow

Q：是否支持 pod 集成？

A：目前暂不支持

Android

Q：接入 SDK 时，是否需要手动通过 FileProvider 将 path 转化为 uri？

A：不需要，直接传入本地 path 即可，sdk 内部会进行 path 转 uri 操作

Q：第一次分享成功，但是第二次分享失败，这是什么原因？

A：鉴权失败了，appKey 和包名不匹配导致鉴权失败，需要核实一下 appKey 和包名是否匹配。（第一次可以分享成功的原因是，鉴权是懒鉴权并且不会阻塞分享流程）

Q：分享失败，错误信息为 “ConvertAvailableUri error. …” 时，应该如何定位原因？

A：检查是否配置了 FileProvider，并且确认 AndroidManifest 文件中是否为 android:authorities=“${packagename}.provider”；如果不是的话，需要在配置项中进行对应设置，代码如下：

XhsShareSdk.registerApp(this, "Your appKey",
	new XhsShareGlobalConfig()
	// 其他配置项
	...)
	// 传入新的 Authority，和 Manifest 文件中的authorities 需要保持一致
	.setFileProviderAuthority("XXXX")


如果确认上述都没有问题，需要检查 file_paths.xml 文件，确保缓存文件夹路径（默认为 /storage/emulated/0/Android/data/yourpackagename/cache/xhs_share_cache_dir，可外部配置）在 root_path 路径下。

Q：分享网络资源（网络图片、网络视频）到小红书时，没有进入发布页，而是进入相册页，应该如何定位？（JS SDK 也适合这条）

A：首先确认网络资源是公网可访问的，以及图片/视频格式为常见格式，如果以上都是正确的话，需要找小红书开发进行进一步问题定位。

HarmonyOS

Q：跳转到小红书，取消分享，为什么不会跳转回 App？

A：小红书分享SDK主要提供了用户分享图片、视频到小红书 App 快速发布笔记。我们目前只在笔记发布成功后设置了跳转回 App的弹窗。

Q：分享网络资源（网络图片、网络视频）到小红书发布页，出现“资源处理错误，请稍后重试”toast提示

A：首先确认网络资源是公网可访问的，以及图片/视频格式为常见格式，如果以上都是正确的话，需要找小红书开发进行进一步问题定位

Q：分享网络资源（网络图片、网络视频）到小红书时，进入发布页会长时间空态

A：网络资源比较大，正处于资源下载阶段

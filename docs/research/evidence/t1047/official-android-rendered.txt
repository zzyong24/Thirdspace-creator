小红书分享 SDK Android 接入指南
SDK 基础信息
KEY	VALUE	备注
小红书最低版本号要求	7.81	
manifest 中声明的权限	android.permission.INTERNET	此权限已经在 sdk 的 manifest 清单文件中声明，接入方无需再次声明
manifest 中声明的四大组件	com.xingin.xhssharesdk.core.XhsShareActivity(exported = true)	此 Activity 已经在 sdk 的 manifest 清单文件中声明，接入方无需再次声明
manifest 中声明的 queries	<package android:name="com.xingin.xhs" />	此 query 已经在 sdk 的 manifest 清单文件中声明，接入方无需再次声明
SDK 包体积	170.3 KB	
前置要求
项目中需要配置 FileProvider，参考链接
和小红书商务同学沟通，提供包名等消息，获取对应的 App Key
集成 SDK

使用本地依赖 aar 的方式集成到项目中。

 

API

备注：以下示例代码均为 Kotlin 代码。

初始化

进行分享之前，需要先对 sdk 初始化。

/**
 * 初始化 SDK
 */
XhsShareSdk.registerApp(context, "appkey",
            XhsShareGlobalConfig().setEnableLog(true).setClearCacheWhenShareComplete(true),
            object : XhsShareRegisterCallback {
                override fun onSuccess() {
                    Log.i("xhs", "onSuccess: 注册成功！")
                }

                override fun onError(
                    errorCode: Int,
                    errorMessage: String,
                    @Nullable exception: Exception?
                ) {
                    Log.i(
                        "xhs",
                        "onError: 注册失败！errorCode: $errorCode errorMessage: $errorMessage exception: $exception"
                    )
                }
            })


参数解析

/**
* 注册 app （即初始化）
* @param context 任意 context 即可
* @param appKey 申请的 appKey
* @param config 一些配置项
* @param callback 注册回调
*/
public static void registerApp(Context context, String appKey, XhsShareGlobalConfig config, XhsShareRegisterCallback callback)


配置项（XhsShareGlobalConfig）

支持的配置如下：

配置项	方法名	含义	默认值	备注
log 打印	setEnableLog(Boolean)	是否打印分享过程中的日志	false，不打印	
log 实现	setShareLogger(IShareLogger)	日志打印方式	系统 Log，打印在控制台	


缓存文件夹	setCacheDirPath(String)	分享过程中缓存文件的存储目录	/storage/emulated/0/Android/data/yourpackagename/cache/xhs_share_cache_dir	1. 配置的缓存文件夹路径需要在 FileProvider 的根目录下
2. 若配置的缓存文件夹非应用私有目录下时，需自行处理文件读写权限问题，SDK 未进行权限判断以及权限申请。
authority	setFileProviderAuthority(String)	FileProvider 将 file 转换为 uri 所需要的 Authority	yourpackagename + “.provider”	
清除缓存选项	setClearCacheWhenShareComplete(boolean)	分享结束后是否清除中间产生的缓存文件夹	true，清除	
使用外部 Activity 注册广播接收分享结果	setNeedRegisterReceiverWithOutsideActivity(boolean)	使用外部 Activity 注册广播接收分享结果	false	如果中间透明 Activity （XhsShareActivity）在分享过程中会被杀掉的话，可以使用此配置来保证可以正常使用分享 SDK。
此选项开启后，分享结果会有 20s 的超时兜底时限，即：如果调用分享后 20s 内接收不到分享结果即认为是分享失败
开始分享

构建分享数据

笔记类型	标题	正文	图片	视频	视频封面
图文笔记	可选	可选	必传，1-18 张	-	-
视频笔记	可选	可选	-	必传，1 个视频	可选，0 - 1 张封面
图文笔记
XhsNote().apply {
    title = getTitleString()    // 正文，String
    content = getContentString()    // 标题，String
    imageInfo = XhsImageInfo(listOf(
        XhsImageResourceBean.fromUrl("网络图片 url"), 
        XhsImageResourceBean.fromUrl("网络图片 url")))            
}

视频笔记
XhsNote().apply {
    title = getTitleString()
    content = getContentString()
    videoInfo = XhsVideoInfo(XhsVideoResourceBean("本地视频 uri"),     // 视频
                            XhsImageResourceBean("本地图片 uri"))    // 封面
                    }


NOTE:

XhsImageResourceBean 支持三种构造方式
new XhsImageResourceBean(File) // 本地图片
new XhsImageResourceBean(Uri) // 本地图片
XhsImageResourceBean.fromUrl(String) // 网络图片或者本地图片。如果入参是网络链接，则是网络图片；如果入参是本地文件路径，则是本地图片
XhsVideoResourceBean 支持三种构造方式
new XhsVideoResourceBean(File) // 本地视频
new XhsVideoResourceBean(Uri) // 本地视频
XhsVideoResourceBean.fromUrl(String) // 网络视频或者本地视频。如果入参是网络链接，则是网络视频；如果入参是本地文件路径，则是本地视频
如果同时设置了图片资源（imageInfo 字段）和视频资源（videoInfo 字段）的话，则认为是图文笔记，废弃视频资源

开始分享

val sessionId = XhsShareSdk.shareNote(context, xhsNote)

context 需要传入 Activity context
sessionId 为本次分享的唯一标识，每次分享都会改变
分享回调

设置分享回调（1.1.0 版本有变更）

XhsShareSdk.setShareCallback(object : XhsShareCallback {
            override fun onSuccess(sessionId: String?) {
                Log.i("xhs", "onSuccess: 分享成功！！！")
            }

            // 1.1.0 版本之后废弃
            override fun onError(
                sessionId: String,
                errorCode: Int,
                errorMessage: String,
                throwable: Throwable?
            ) {
                Log.i(
                    "xhs",
                    "onError: 分享失败!! $sessionId $errorCode $errorMessage $throwable"
                )
            }
            
            // 1.1.0 版本后提供的新错误回调，内含新的错误码
            override fun onError2(
                sessionId: String,
                newErrorCode: Int,
                oldErrorCode: Int,
                errorMessage: String,
                throwable: Throwable?
            ) {
                Log.i(
                    "xhs",
                    "onError: 分享失败!! $sessionId $newErrorCode $oldErrorCode $errorMessage $throwable"
                )
            }

        })


注意：设置分享回调时，注意内存泄露。

移除分享回调

XhsShareSdk.setShareCallback(null)

判断是否支持分享笔记到小红书

/**
 * 是否支持分享笔记到小红书
 * 判断条件：
 * * 小红书 app 是否安装
 * * 小红书版本号是否满足要求
 */
VersionCheckResult XhsShareSdkTools.isSupportShareNote(Context))

/**
 * VersionCheckResult 数据结构
 */
public class VersionCheckResult {
    
    /*
    * 检测结果：
    * 0 - 支持分享
    * -1 - 小红书未安装
    * -2 - 小红书版本号不满足要求
    */
    @ResultCode
    public int checkResultCode;

    @NonNull
    public String errorMessage;

    @Nullable
    public Throwable exception;
}

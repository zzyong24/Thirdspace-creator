# T-915：开场工具接入真实定义与动态工厂

持久聊天准备在宿主提供开场生成配置时，将实际挂载的 script.hooks 声明为 Worker 执行。旧聊天准备默认保持原版本和字段；其他工具定义不变。

```mermaid
flowchart LR
 A[真实聊天准备] --> B[冻结工具定义与配置]
 B --> C[动态工厂读取原任务]
 C --> D[核对账号与完整工具定义]
 D --> E[原参数和授权规则]
 E --> F[Worker 生成开场候选]
```

新工厂读取真实 host context reader，从原业务工具构造参数、版本和授权规则。授权时再次读取任务，验证账号、冻结配置和完整定义。工厂不返回旧模型执行闭包；实际 script.hooks 当前没有额外审批规则。已有规则如果返回无效值，不能被当作免审批。

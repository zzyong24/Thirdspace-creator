# T-915：原音频恢复与本地转写取消

本批将原音频保存在账号所属对象存储，执行任务只保存键、摘要和长度。音频确认可回读后才能预留云端识别请求；恢复使用同一份字节，避免重新抽音导致分片进度失配。

```mermaid
flowchart LR
  A[原音频] --> B[锁定摘要与存储键]
  B --> C[写入并回读校验]
  C --> D[确认原输入]
  D --> E[逐片识别账本]
  E --> F[恢复时复用已完成正文]
```

存储写成功但响应丢失时，回读实际字节可恢复确认状态。不同正文不能覆盖原输入；已确认对象丢失或损坏会明确报错。写入中取消只保存已发生的事实；更换执行凭证后旧执行不能更新确认状态，新执行校验原对象后恢复。没有新增任务队列或数据表。

本地 Whisper 取消会传递到解码和推理。正常取消等待进程或线程退出；终止调用失败时保留退出屏障。解码器终止失败会报告错误，并在旧进程关闭前阻止同实例再次启动。未验证操作系统永不发出退出事件时的自动恢复。

验证：音频与 ASR 两文件 24 项、本地 Whisper 两文件 38 项、调度与进程生命周期三文件 26 项，共 88 项通过；backend、ai-worker、frontend 类型检查退出 0。新增测试覆盖不同字节并发首次保存、写入中取消和凭证变更、真实临时文件存储结合 Qwen 分片适配器的重复执行。供应商响应为测试替身，第二次执行没有新增请求；未运行付费供应商或安装包验收。所有新增存储测试使用独占临时目录和隔离数据库。

真实失败记录：初次音频模块不存在是加载失败，不能冒充行为红测；未保存音频仍可预留 ASR 的断言曾失败，修复后通过。Whisper 的取消、终止失败与解码屏障均保留当场红绿日志。主线第一次增量 preflight 因已有文件哈希过期被拦，更新精确文件登记后通过。frontend 初次包名筛选没有匹配项目，已按实际包名重跑成功，不计作首次通过。

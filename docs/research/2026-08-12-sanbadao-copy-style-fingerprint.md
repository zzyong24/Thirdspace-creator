# 三把刀文案风格指纹（用于 `script.draft` Skill 迭代）

> 来源：腾讯文档《文案三把刀100条爆款文案实战手册》。抽样覆盖认知、成长、商业、短视频方法、产品与案例类内容。本文只提炼可迁移的写作机制，不复制原文，不采用其未经核验的事实、夸张收益或攻击性措辞。

## 一句话结论

三把刀文案不是“把知识讲清楚”，而是**选中观众正在相信的一个判断，连续施压，直到旧判断站不住，再把作者的新判断钉进去**。

## 七个稳定动作

### 1. 先找论敌，不先找结构

每篇都有一个明确要推翻的旧判断，例如“短板必须补”“投机等于不劳而获”“HTML 会淘汰 Markdown”这类可被攻击的命题。作者不是围绕主题介绍知识，而是在和一个具体判断对打。

### 2. 开头是立场动作，不是固定句式

样本开头至少有四种：直接判决、挑衅式提问、反常识结论、真实事件/案例。共同点不是“结论前置”，而是第一句话已经制造立场冲突。不能把其中一种固化成模板。

### 3. 论证靠连续施压

典型推进是：

`旧判断 → 直接否定 → 观众可能反问 → 类比/反例/推演 → 新定义 → 行为后果`

每一步都让旧判断更难维持。它不是“第一、第二、第三”的并列知识点，而是一个结论被多种证据包围。

### 4. 类比负责把抽象观点打进生活经验

常见手段包括极端人物对照、动物或日常场景、商业案例、反事实推演。类比的作用不是装饰，而是让观众在熟悉场景中先承认一个判断，再把判断迁回主题。

### 5. 把观众拉进一场假想对话

高频出现反问、追问、预判异议和自问自答，例如“合理吗”“你发现没有”“那你肯定想问”。这让口播像当面辩论，而不是课程讲义。

### 6. 作者态度是推理的一部分

“我告诉你”“说难听点”“扯犊子”等态度词用于给判断定性，建立作者敢下结论、敢承担立场的形象。可迁移的是**明确价值判断和说话者身份**，不是机械复制脏话或攻击性。

### 7. 重复分为加压与注水

同一结论可以重复，但每次必须换一个压力来源：反例、类比、后果、身份判断或观众异议。只换同义词的重复是注水；从另一侧继续封死旧判断，是风格核心。

## 定位在文案里的真实作用

定位不负责替作者提供内容，也不只负责称呼受众。它决定：

- 作者凭什么有资格下这个判断；
- 作者站在哪一边、反对哪一种行业常识；
- 可以使用多强的语气、多锋利的判断；
- 用哪类案例和比喻，才能让目标观众立刻代入；
- 最后把观众推向哪一种身份或行为。

所以定位是“立场与证据选择器”，不是一段需要复述进正文的背景资料。

## 不能照搬的表层特征

- 不能固定用“你知道吗/我告诉你/扯犊子”开头；
- 不能为了锋利把局部经验写成普遍真理；
- 不能模仿夸张收益、绝对数字和未经核验的名人案例；
- 不能把所有稿子都写成清单；
- 不能把粗口当成人设，把反问当成逻辑；
- 不能为制造论敌而曲解用户真实观点。

## 对 `script.draft` 的首个单变量假设

在正式写稿前，只增加一项内部动作：

1. 写出观众当前相信的一个具体旧判断 A；
2. 写出作者要建立的新判断 B；
3. 从真实素材中选择 2–3 个不同的施压动作：反例、类比、因果推演、预判异议、亲历案例；
4. 成稿时不展示 A/B 标签，不按动作名称分段；每一段必须继续削弱 A 或增强 B；
5. 没有足够素材支撑时缩小 B，不得编事实补论证。

固定公式、定位、事实约束和输出 schema 暂时都不改，确保下一轮只测试“认知对打”这一变量。

## 验收口径

- 明确公开：允许新建/更新项目、发布、指标和后续派生物。
- 明确隐藏：自动导入项目整体删除；手工项目只删除对应平台 publication 子树和平台派生物。
- 无法判定：不新增、不清理，不把未知冒充公开。
- 恢复公开：源扫描不使用本地已知作品提前停止，下次可重新发现并采入。
- 旧隐藏字段仅暂留作存量归一与升级兼容，不参与下游查询、聚合、重活或 UI 过滤；首次真实
  对账已完成。

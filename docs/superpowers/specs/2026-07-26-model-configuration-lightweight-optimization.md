# T-501 模型配置轻量优化（替代范围）

状态：用户已确认，可直接进入 BUILD。
日期：2026-07-26

## 为什么改

CreatorOS 的模型设置页已经成型，不需要重做模型平台、能力总览或配置向导。当前真正的问题只有：

1. 普通用户被提供商标识、Base URL、协议、温度等字段增加了配置负担；
2. “测试连接”与正式聊天不是同一调用通路，会把网页 `200` 或 `2xx` 空流误判为成功；
3. New API、中转站和 Kimi 两套入口缺少能直接照填的教程。

## 本次只做三件事

- 主路径只显示供应商预设、模型 ID、API Key；其余字段收进“高级设置”；
- 主模型提供“保存并测试”，先保存当前填写，再复用正式 `modelFor + streamText` 通路，
  只有收到非空文本才算连通；
- 更新应用内配置手册和仓库教程，覆盖官方预设、New API / 中转站、Responses、Kimi
  开放平台与 Kimi Code。

## 明确不做

- 不新增页面，不改变 AppShell 或 Settings 主信息架构；
- 不做八槽总览、能力矩阵、模型商城、配置向导或费用平台；
- 不新增付费图片/视频探测，不依赖 T-517；
- 不修改现有 `settings.models.put` / `settings.models.test` 的公开契约形状；
- 不承诺一次轻量探针验证复杂工具调用，只验证正式模型工厂下的基础流式文本通路。

## 验收

- 选择官方预设后，普通用户只需填写模型 ID 和 API Key；
- 自定义中转站能展开高级设置填写 Base URL 与 Chat / Responses；
- 点击“保存并测试”时，保存一定发生在测试之前；
- HTML `200`、空流、无文本均不得显示“连通”；
- Kimi 开放平台与 Kimi Code 使用不同预设和正确的 OpenAI Chat 地址；
- 定向单测和前端类型检查通过。

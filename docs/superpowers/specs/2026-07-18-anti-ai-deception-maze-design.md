## 0. 用户拍板方向(单一真值)

用户 2026-07-18 采纳范围:纯假诱饵污染 + **零功能影响**(不改任何真实执行路径,真实用户完全无感,不引 bug、**运行时无可测退化**、不增脆性;非运行时的静态成本——包体/签名/扫描——受 §4 预算阈值约束)· 打包后无真注释(可留假注释)· AI 可见的攻击面上尽量是误导 · 反注入紊乱撑爆破解 agent 上下文。**显式排除**:主动 prompt-injection 攻对方 agent、chaff-bug 诱饵漏洞、任何"检测到就投毒/损坏"的主动对抗响应(误伤正版=灾难)。只做**被动欺骗**。

## 1. 设计红线(不可违背;codex FAIL 处置后收紧)

- **R1 零真实路径改动**:真授权结论已在 Rust `run_license_chain`/`apply_runtime_gate` 原生多点复算(H-native 已建)。本层只加旁路诱饵,一行不碰真门判定与数据流。
- **R2 诱饵纯静态·永不加载执行(blocker B-1 处置 + re-gate Major-1 处置:执行模型二选一 → 选「永不执行」)**:诱饵是**只存在于分发物、从不被加载/调用/求值**的静态制品(死代码 + 字符串 + 假注释,进默认不加载的独立 chunk/resource)。它无运行时行为,故 trivially 不进任何 UI / 日志 / 遥测 / 业务状态——**不存在"隔离 sink 运行时写入"**(那反而引运行时)。诱饵的价值 = AI 静态读分发物时找到可信假线索浪费时间,不来自任何可见反馈。**放弃"强化 patch 成功错觉"**(违"诚实而非热闹"+ 零功能影响)。
- **R3 纯静态不可达可证(blocker B-2 处置 + re-gate Major-1/Minor-2 处置)**:承诺收窄为"诱饵**从生产入口静态不可达、生产代码零引用**",三条机器可判断言(**取代运行时五态测试**——诱饵不执行,无 throw/hang 语义):①调用图中诱饵从生产入口不可达;②生产模块对诱饵导出的引用数 = 0(lint/依赖规则强制);③打包版冒烟 + 全测运行时诱饵执行计数 = 0。删除/任意篡改诱饵 → 主产物构建与主路径运行逐字节等价(双次构建哈希比对)。
- **R4 真注释零泄露 + 假内容有内部溯源(major 处置)**:分发物无真实架构注释;假内容带**机器可识别但不暴露给平凡静态检索**的内部 provenance + 可复现构建 manifest(防己方排障/审计/AV 扫描被自己的假注释坑)。
- **R5 确定性可复现(major 处置)**:诱饵由**受控 seed + 版本号确定性生成**;固定工具链版本;双次构建产物哈希一致;不留长期明文总映射。

## 2. 四个诱饵维度(全部须过 R2/R3)

### D1 蜜罐授权门(honeypot · 纯静态死代码)
- 分发物内一处**像模像样的假验签门**静态代码(ed25519 形态 + `expiresAt` + grace-period),命名/结构比真门更浅更标准更好找,吸引 AI 先扑——但**从不被任何生产入口引用/调用**(R2/R3:静态不可达、零引用)。价值 = AI 静态读到可信假门浪费时间。
- **反向暴露防护(major 处置)**:威胁模型显式评估"识破诱饵后的信息增益"——不得在假门留可推断"真门在 Rust/native"的边界特征(假门旁不留 native bridge 调用痕迹);且 §4 盲测必测"攻击者按 chunk 整体排除诱饵后仍有净收益"(re-gate Minor-1)。
- 验收:R3 三条静态断言(不可达/零引用/执行计数 0)。

### D2 符号/字符串/假注释污染(构建期注入,进独立 chunk)
- 攻击面上散布诱饵字符串 / 误导命名(`validateLicense` 等)/ 描述假架构的假注释。真门早已 Rust + obfstr 灭靶点(m-1:附录给 `nm`/strings 验证法证明 Rust 侧无有意义授权符号)。
- 构建期注入,与 R4"真注释零泄露 + 假内容溯源"同一管线。

### D3 死代码迷宫(严格不可达,禁"半死")
- **删除"dead-ish/半死"表述(major 处置)**:只允许**构建产物中严格不可达的数据**或**经形式化限制的纯函数**;明确允许的 AST 节点 + 禁止的副作用;编译后做控制流 + 调用图检查,断言诱饵路径覆盖率 = 0%。

### D4 上下文污染(量化目标,非"全假")
- **"AI 能看到的全是假的"不可验收,改为攻击面量化目标(major 处置 + re-gate Major-2 填实)**:"**授权相关静态候选(函数/字符串/注释中命中 license/verify/expire/entitlement 等锚词者)中诱饵占比 ≥ 40%**,且 §4 盲测证真门定位成本 **+≥ 50%**"。统计口径:纳入分发物 JS chunk + 二进制 strings;分母=锚词命中的静态候选总数,分子=其中确认诱饵数(对映射表)。初值 40%/50% 为开工目标,由 T-399c 盲测 spike 校准后固化(校准法与拐点见 §4.3)。

## 3. 落点与构建管线

- 注入点:`obfuscate.mjs` 扩"诱饵注入 pass";**诱饵进独立、默认不加载的 chunk/resource(major 处置——防启动/解析/签名/AV 扫描成本)**,不进启动 chunk。**独立 chunk 反被识别风险(re-gate Minor-1)**:承认它可能成为"整包忽略诱饵"的特征 → §4.3 盲测把"按 chunk 整体排除后是否仍有净收益"列为必测攻击策略,无净收益则该维度淘汰。
- **管线自审(major 处置——管线是新攻击面/单点)**:`obfuscate.test.mjs` 扩:注入前后真实代码 AST 不变性、注入量计数准、映射一致、注入痕迹不可平凡识别、tree-shaking/minify 后诱饵仍在且不进主可执行路径、语法/加载/双次构建一致性、签名前后顺序。
- **映射(R5 + major 处置)**:seed 派生 + 版本号确定性生成,seed 进受权限管理的秘密系统;产出**加密、带版本+哈希的审计清单**;定义轮换/恢复/泄露处置流程。**放弃 gitignore 明文总映射**(破坏可复现构建 + 是"破解答案")。
- **R4 真注释断言范围明确(major 处置——纯 grep 既漏又误)**:从**源码 AST 标记 dev-only 内容**,产物层验证标记不可达;扫描范围含 source map / licenses / 资源 / 错误消息 / 路径 / 模块名 / 二进制 strings,配 allowlist 防正常用户文本误命中。

## 4. 验收(量化;codex minor 处置——阈值不留到实现时口头约定)

1. **零功能影响可证(re-gate Minor-2:静态可达性与运行时执行分开验)**:`pnpm verify` 相关包全绿 + 打包版冒烟通过 + R3 三条断言全过——①调用图中诱饵从生产入口不可达;②生产模块对诱饵导出引用数 = 0;③冒烟+全测运行时诱饵执行计数 = 0(不再用混淆"静态覆盖率"一词)。
2. **性能退化受预算约束(major 处置 + re-gate Major-3 措辞:不再号称"零性能影响")**:诱饵永不加载 → **运行时冷/热启动、RSS 在测量误差内无退化**(诱饵进不加载 chunk,不解析不执行);仅**非运行时静态成本**受预算——安装包 ≤ 基线 +**5%**、签名/公证时间 ≤ +**5%**、升级差分包增幅 ≤ +**10%**;超阈即 build fail。
3. **§4.3 欺骗有效性盲测(blocker 级——现有指标只证"塞进去了"不证"有效";re-gate Major-2 填实统计判据)**:同版本生成 control / decoy 两组,固定模型/提示/工具权限/时间预算,**每组重复 ≥8 轮**;衡量:真门定位成功率、首次错误 patch 比例、有效破解时间、token/工具调用量、功能测试结果;**必测攻击策略含"按 chunk 整体排除诱饵"(Minor-1)**。**判据(取代模糊"显著")**:decoy 组真门定位中位耗时/尝试数 ≥ control 组 **1.5×**,且 Mann-Whitney U 检验 **p < 0.05**;不达标则该维度淘汰,不留"纸老虎"。X=40%/Y=50% 初值由本 spike 校准后固化。
4. **真注释零泄露**:R4 的 AST 标记 + 产物层不可达验证通过(非仅关键词 grep);扫描全范围无真架构信息。
5. **诚实边界写入(minor 处置——位置明确)**:新立 `docs/engineering-notes/security-posture.md`(不改宪法,避产品变更流程),记:本层=security-by-obscurity 成本抬升实验,专坑自动化 AR;**客户端不存在绝对不可破**(Frida 运行时 hook 挡不住);治本轴=服务端签名 + 每机指纹 + 每版本重生成。
6. **构建期开关 + 紧急回退(minor 处置)**:诱饵注入是构建期开关,可验证 clean build;定义触发回退指标(启动退化/AV 误报/公证失败/崩溃)。**开关不得远程改变已发布客户端行为,也不得成为授权旁路**。

## 6. 本地对抗自审 findings(内部审,不出仓——本 SPEC 是防外部 AI 的,不再送外部模型;戴攻击者帽子自查)

- **SA-1(结构性·最重要):纯静态零引用诱饵 = 天然可被调用图剪枝。** 为过 codex 零功能影响 blocker,D1/D3 收成"永不加载、零引用"——但**懂调用图分析的破解 AI 一句"无 caller 即死代码,整体忽略"就能剪掉全部 Class A 诱饵**(codex Minor-1 已触及)。→ **诱饵分两类,真价值在 Class B**:
  - **Class A 伪造静态诱饵**(假蜜罐门/死代码/诱饵字符串,不加载 chunk,零引用):零功能影响易证,但可剪枝——**留存与否由 §4.3 盲测「chunk 整体排除后净收益」裁决,不过则砍**。
  - **Class B 真代码的误导化**(把**真实可达**符号/注释改成误导名——`formatDate` 承载真校验、`validateLicense` 是遥测;真门旁真代码配假注释):**不可剪枝**(剪了功能就坏),这才是抗调用图分析的主力。零功能影响由「**纯重命名/改注释、行为保持**」证明(复用 obfuscate 既有 AST 不变性测试),**不属"死代码"、就在真实加载路径**——与 R2"诱饵不加载"是两条正交轴:Class A 靠不加载证无害,Class B 靠 rename-only 证无害。
  - **主次调整**:D2/D4 以 Class B 为主(un-prunable),Class A 为辅(廉价噪声,盲测存活才留)。
- **SA-2:本 SPEC + 母调研 = 皇冠明珠,绝不可进任何分发物或外部服务。** 已停外部 gate;硬前提:`docs/` 全量在 T-392 剥离表内(核验分发物 grep 不到本 SPEC/调研任一句)。**其自身即本层要防的"设计文档泄露"最高目标。**
- **SA-3:seed 是真钥,泄 seed = 诱饵全暴露可批量剪。** 构建期 seed 走 CI secret(GitHub Actions secret),**禁进 CI 日志/产物**;每版本轮换;泄露处置=换 seed 重出版本(与"每版本重生成"治本轴同源)。

# T-794 内容驱动动效卡片迭代 SPEC

**状态**：用户已确认，BUILD 中

**范围**：`video.cards` Skill、内部视频卡片决策契约、既有 HyperFrames/GSAP 卡片渲染与验证

**不做**：新页面、新数据表、第二套视频引擎、音效、AI 直写代码或绕过制作确认

## 1. 问题与目标

当前卡片虽然已有 `counter / bar / reveal / strike / metaphor / plain` 动画标签，但信息仍被压成一段
`content`。组装器再按标点猜结构，渲染器多数时候只让整张圆角卡淡入、错峰上移或补一根通用色条。
因此不同内容最终都像“字冒出来”，动画没有帮助观众理解口播里的关系。

本轮把卡片从“有动画的文字容器”升级为“内容驱动的视觉句子”：AI 只在有依据时声明数字量级、
对比、步骤、因果、替换或陈述关系，并从口播原文抽取组成部分；确定性代码只校验溯源、守版式边界，
再把关系落成固定可测试的 GSAP 配方。

## 2. 内部契约

`video.cards` 的每张卡保留现有 `kind / content / at / motion`，新增可选 `visualPlan`：

```json
{
  "relation": "magnitude | contrast | sequence | cause_effect | replacement | statement",
  "parts": [
    { "text": "口播原文片段", "role": "subject | measure | old | new | step | cause | process | result | claim | evidence | conclusion" }
  ]
}
```

- `parts` 为 1–6 个；每段文字必须能在口播原文中追溯，不能改写、补事实或编数字。
- `visualPlan` 不合法时只丢弃该计划，仍保留可溯的旧卡片，保证弱模型和历史候选兼容。
- 关系选择属于 AI/Skill 的创作判断；代码不得用关键词、相似度或业务名称替 AI 选关系。
- 没有计划时，代码只按模型已经给出的 `kind / motion` 执行既有兜底，不声称理解了新语义。

## 3. 六种视觉句子

| 关系 | 画面过程 | 验收信号 |
| --- | --- | --- |
| magnitude | 先建立对象，再长出量级轨道/数字，最后锁定说明 | 不是整卡缩放；数字与语境分两拍出现 |
| contrast | 先完整建立旧侧，再由中间过渡带切到新侧 | 先看懂旧状态，再看到差异，不是两栏同时弹出 |
| sequence | 节点与连接线按顺序前进，当前节点获得焦点 | 步骤之间的先后关系可见 |
| cause_effect | 原因→过程→结果逐段建立，连接方向随之点亮 | 静音也能看懂因果方向 |
| replacement | 旧判断先成立，再被擦除/退场，新判断接管舞台 | 是“建立→推翻→替代”，不只是划一根红线 |
| statement | 结论按语义片段遮罩揭示，证据/收束随后落位 | 不做整块卡片淡入或装饰性绿线 |

所有配方复用当前信息舞台、字幕安全区、人物完整展示和主视觉互斥规则。不得覆盖字幕、拉伸或裁切
人物；同一 beat 只保留一个强视觉。

全片底层使用低对比细虚线网格与局部辉光，作为信息推演的稳定背景；网格只提供空间秩序，不能比
人物、字幕或关系节点更亮，也不能用高频移动制造摩尔纹。

## 4. Skill 指令

`video.cards` 必须先回答“观众需要看见什么关系”，再选择卡片外形和动画。只在关系能由原文片段
组成时填写 `visualPlan`；不要为了动画硬凑因果、对比或数字。提示词要给出每种关系的正例结构与
反例：整卡淡入、所有字同时出现、通用发光/绿线、只换颜色不改变信息过程，均不算视觉化。

## 5. 兼容与边界

- 旧 `video_decisions`、未产 `visualPlan` 的弱模型和现有六种卡片继续可渲染。
- 不新增公开 API、数据库字段或持久化迁移；新增字段只存在于内部候选/渲染 props。
- AI 仍只产候选，用户确认后才进入现有渲染链。
- 真实图片/录屏继续优先于信息卡；卡片不能遮住随后到来的主素材。

## 6. 评分 Loop 与晋级门

冻结三类同题样本：数字量级、输入→处理→输出的流程因果、保存对话≠理解用户的建立后推翻。
旧版与新版匿名按 `ai-worker/evals/motion-card/content-driven-motion-rubric.md` 评分。

新版必须同时满足：

1. 三题平均分较旧版至少提升 15 分，且每题至少提升 8 分；
2. “关系可见 + 渐进揭示”平均分不下降；
3. 零硬失败；
4. prompt、runner、组装器、contract、renderer 聚焦测试全绿；
5. 横版与竖版真实浏览器预览中，人物/字幕安全区无回归，且至少三类关系不是整卡淡入。

## 7. 完成定义

- `video.cards` v2 能稳定产出可选、可溯源的 `visualPlan`。
- 至少 magnitude、contrast、sequence、cause_effect、replacement 有独立 DOM 与 GSAP 过程。
- 无计划的旧候选正常渲染；坏计划诚实降级，不伪造成功。
- 同题前后评分、聚焦测试、真实预览与项目 Gate 留下可复验结果。

# CreatorOS 官网公开价格与个人联系方式收口 SPEC

> 任务：T-672  
> 日期：2026-08-03  
> 状态：用户已确认产品方向；待独立评审后进入 BUILD。

## 1. 目标

CreatorOS 官网用于帮助代理向客户解释产品，而不是提供绕过代理的直营报价和个人联系入口。
为保护代理的线索归属与利润空间，官网从公开价格真相页调整为产品能力说明页。

## 2. 当前唯一公开边界

- 继续公开：产品定位、功能飞轮、真实产品截图、本机数据、支持平台、一机一码、更新日志。
- 不再公开：终端售价、内测价、正式版价格、续费价、代理进货价、指导价、利润、价差、价格截止日期。
- 不再公开：作者个人微信、备用微信、个人邮箱、个人二维码，以及“直接联系作者/加我微信/私聊购买”等直营入口。
- 获取方式只保留一句中性指引：**请联系向你推荐 CreatorOS 的授权合作伙伴，了解适用方案、交付方式与当前政策。**
- 官网不得提供绕过分享者的官方直销联系方式；代理内部政策、价盘与联系网络继续由 Growth/渠道运营体系管理，不写入公开静态站。

## 3. 页面调整

1. Hero 删除价格、截止日期、首购/代理价盘和咨询购买按钮，只保留产品定位与查看能力的入口。
2. 原价格区改为“适配与交付”信息区，仅说明一机一码、当前支持 Apple 芯片 Mac 与 Windows、Intel Mac 适配推进中。
3. 原代理价盘区改为“通过授权伙伴获取”，不展示代理门槛、进货价、指导价或利润。
4. 页尾删除二维码、微信、邮箱和复制联系方式控件，改为无链接的授权伙伴指引。
5. 智能客服遇到价格、购买、代理或联系方式问题时，不报价、不返回个人联系方式，只提示联系向用户推荐 CreatorOS 的授权合作伙伴。
6. 删除已部署个人二维码静态资源，防止通过历史直链继续访问。

## 4. 数据与契约边界

- 本任务只修改静态官网、静态资源和官网回归测试。
- 不修改 CreatorOS 客户端、Activity 激活码、Growth 商品/渠道价盘、代理身份或订单结算。
- T-668 记录的历史公开定价已被本 SPEC 取代；内部商业规则不因官网撤下而自动失效。

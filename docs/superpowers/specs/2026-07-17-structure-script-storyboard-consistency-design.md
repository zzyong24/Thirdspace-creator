# SPEC:结构·口播·分镜·素材 一致性契约(T-387)

> 用户 2026-07-17 拍板问题:「结构、口播、分镜一定要一致,不一致后面视频怎么做?」+
> 「论点挂素材该 AI 预设(人可改),缺素材要引导补,图文并茂」+「脚本画面列的素材该自动进 B-roll」。
> 改创作链语义(四决策从再创作降为对齐器)→ 常规审后拆片。

## 0. 一句话定义

确立**分层单一真源**:论点树=论证骨架 / 口播稿=内容语义 / 脚本「画面」列=authored 视觉意图 /
SRT=时间。四决策从「再创作者」降为「**对齐器**」(尊重 authored 意图,只补空白);素材链全程
AI 预挂 + 自动聚合进 B-roll + 缺口显式引导补。

## 1. AS-IS(源码证据,三处断裂)

1. **四决策不读脚本画面列**:video-decisions.ts 模板只吃 SRT+口播稿纯文本;script.draft 产的
   三栏(口播/画面/字幕)里「画面」只是正文文本,无结构化字段、无人消费 → 制作阶段 AI 重新
   发明 scenes/cards/broll,与 authored 分镜必然漂移。
2. **论点挂素材只有人挂**:thesis-skeleton-panel.tsx `materialRefs` 机制在(:74,:90 挂/去重),
   注释明写「AI 预挂=后续增量」(:42)——planning.thesis 产树时不做素材匹配。
3. **B-roll 备料孤岛**:production 备料③手动上传;脚本画面列点名的素材、论点已挂素材、项目
   弹药里的图/视频都不会自动进 B-roll 候选。

## 2. 一致性契约(核心裁决)

| 层 | 真源 | 冲突时 |
|---|---|---|
| 论证骨架(为什么讲) | 论点树(采纳版) | 口播稿采纳后,语义以口播稿为准(树是脚手架) |
| 内容语义(讲什么) | **口播稿当前版本**(用户采纳/编辑的) | **最高语义权威** |
| 视觉意图(配什么画面) | **脚本「画面」列(authored)** | 四决策必须尊重;仅 authored 空白的镜才自主补 |
| 时间(何时) | SRT(既有铁律,不变) | 恒为时钟真值 |

**四决策角色重定义:对齐器**——把 authored 画面意图落到 SRT 时间轴 + 补全空白镜,
**绝不推翻 authored 意图重新发明**。字幕决策(文本校正)不变。

## 3. 设计(三条链)

### G1 论点树 AI 预挂素材(人可改)+ 缺口引导
- planning.thesis runner 产树后:对每个支撑/证据节点,从**项目弹药**(ammo:知识+素材)按标题/
  要点相似度匹配 1-2 条 → 预填 materialRefs(标 source:"ai" 以区分人挂,UI 可整条移除/替换)。
- 匹配不到的证据节点 → 节点上渲「缺素材」徽标 + 一键动作(搜素材(联网)/上传/AI 生成),
  即用户要的「支撑依据+支撑素材,图文并茂」。
- 铁律:预挂只引用**真实存在**的弹药,绝不虚构;匹配置信度低宁缺勿滥(缺=诚实徽标)。

### G2 脚本「画面」列结构化 + 素材点名
- script.draft 输出 schema 的 section 增加结构化 `visual` 字段(画面描述文本 + 可选
  `assetRefs[]`(点名项目内真实素材 assetId)+ `missing[]`(需要但没有的素材描述))。
  模板指令:画面列优先引用项目已有素材(素材清单已注入),没有的如实进 missing,不虚构。
- 稿面结构视图渲染 visual(现三栏文本格式向后兼容:旧稿无 visual 字段照旧渲文本)。
- 采纳整稿时 missing 汇总为项目「缺素材清单」(挂稿面弹药区,带搜/传/生成入口)。

### G3 四决策=对齐器 + B-roll 自动聚合
- **B-roll 备料自动聚合**:production 备料③自动列入——脚本 visual.assetRefs 点名的素材 +
  论点树 materialRefs 里的图/视频 + 项目弹药中的 image/video 资产(统一去重);手动上传仍可加。
  UI:自动项标来源徽标(「来自脚本画面」「来自论点」「弹药」),人可剔除。
- **四决策吃 authored 意图**:video.scenes/cards/broll 模板新增 facet `storyboard`(结构化的
  per-section visual 意图 + assetRefs);指令改为——有 authored 意图的时间段:scene 切分对齐
  section 边界(吸附 SRT)、broll **必选点名素材**、cards 不与 authored 画面冲突;无意图段才
  自主决策。runner 侧透传;旧项目无 visual → facet 空,行为=现状(零回归)。

## 4. 不做
- 不改 SRT 主时钟铁律;不做时间轴编辑器(P-06);不虚构素材(缺=诚实)。

## 5. 切片
- **T-387a(G1)**:thesis AI 预挂 + 缺素材徽标/引导。
- **T-387b(G2)**:script.draft visual 结构化 + 缺素材清单 + 稿面渲染(向后兼容)。
- **T-387c(G3)**:B-roll 自动聚合 + 四决策 storyboard facet 对齐器化。
- **T-387d**:真机验(一条从论点→脚本→制作全链,authored 画面被四决策尊重;B-roll 自动出现)。
> 依赖:b→c(storyboard 来自 visual);a 独立。

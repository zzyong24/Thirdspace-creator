# 工作台与分析

适用：首页、创作者总览、定位、运营分析。

首页突出当前创作与继续操作；待办及建议在辅助栏。总览先指标再图表。大屏双栏，1199px 以下分析图表堆叠，手机两列指标。空值显示真实 0 或未采集。

其余配色、字号、间距、控件状态与可访问性要求继承 ../MASTER.md。

## 页面标题去重

普通页面由正文承载主标题，顶部工具栏只保留搜索、通知等操作，不重复页面名称或描述。侧栏的目的地名称与选中状态仍保留。项目编辑器中的项目身份与工作面导航继续显示，避免编辑时丢失归属。

独立预览的真实数据折叠区继承外层页面标题，嵌入的总览、发布和报表组件传入 `showPageHeading={false}`，仅去掉重复主标题，保留筛选、指标、日历及操作。组件独立使用时默认保留主标题。

## 定位对话

仅定位中心的 positioning 浮层使用专用布局。大屏采用说明侧栏与对话主区；可调整窗口以容器宽度响应，窄屏将母版保护提示放到顶部。三个起点仅预填文字，替换起点保留入口资料和手写草稿，不自动发送。模型未配置时保留真实状态、设置入口和禁用发送。历史记录、新对话、附件、消息及候选采纳复用既有逻辑。

输入区保持可见，短横屏允许整个对话区滚动。起点按钮、输入框与关闭按钮有清楚名称及焦点边框；Esc 关闭后返回定位入口，包含原链接重绘的情况。当前配色、字体和间距继续继承主系统，不影响其它入口的通用助手。

定位说明压缩为“说现状 / 补关键点 / 看候选”，不再嵌套说明滚动区。新对话仅预填简短开场；恢复旧会话时仍完整携带路径、选择和自由文本。对话节奏及工具规则由原有 chatbox.positioning 系统模板承担，不重复塞进用户输入框。支持 field-sizing 的浏览器按输入内容自适应到 160px，超长资料保留滚动和手动调整；其它浏览器保留原 textarea 回退。

首次定位在页面主体显示“定位对话”；已有定位母版后隐藏该模块，仅保留右上角“重新定位”。母版、规则、历史和编辑操作保留，显示变化不修改定位数据。

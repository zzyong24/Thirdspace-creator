# 资料与创作资源

适用：内容雷达、选题、知识库、素材、画布列表。

目录/筛选、内容列表、详情三层。大屏支持三栏，平板详情下移，手机按任务顺序堆叠。文档与媒体内容使用自身排版，不改成品颜色与比例。

其余配色、字号、间距、控件状态与可访问性要求继承 ../MASTER.md。

## 内容雷达操作顺序

按“01 来源与采集 → 02 挑选内容 → 03 阅读核对 → 04 改写创作”组织。来源入口先于列表，逐字稿与来源证据先于改写操作；生成、采纳和项目创建保留原有条件与回调。独立预览将样例列表、阅读、创作分区，真实来源配置按需展开，首次展开前不挂载工作台。桌面横向比较，平板创作区下移，手机按步骤纵向堆叠。模拟内容保持明确标识，不能伪装成已采集或已生成。

### 内容雷达完整工作台列宽与真实密度（T-1384）

用户2026-10-21以11来源、5分类、40作品授权替代T-1383断点。配色、字体及共享组件继续继承MASTER。实际工作台宽度至少820px时使用240px来源列、至少280px作品列、至少300px详情列，作品/详情余量按1/0.9分配；1440px及1280px窗口保持三栏，各自独立滚动。可用宽度至少1320px保留详情拖动与键盘调宽，继续记忆320–640px宽度。

可用宽度560–819px来源与作品并排，第一行至少520px或65dvh，详情下移；更窄时来源360px、作品至少520px、详情依次显示。不能用无最小高度的隐式网格行压缩列表。来源管理嵌入模式继续随内容增长。

来源名、分类名和作品标题最多两行并用title保留完整提示；作品详情显示完整标题。分类仅按真实parentId排列，子分类缩进并标明父级，缺父级不丢弃。保留我的收藏/黑马发现的图标、说明、真实计数与空态。来源直接同步，自动开关/运行记录/移除放入原Radix管理菜单，保留同步中移除禁用与删除确认。失败/需登录/受阻等状态同时用文字与语义色显示。

作品用48px封面缩略图，缺图或图片加载失败用中性占位，禁止生成假封面；长作者截断并保留提示，数字沿真实值与未知值。升级状态与指标并排，查看项目及取消保持原回调；唯一升级入口仍在详情04，未知转写显示状态未知。筛选区三等列，标签在上、选择器在下；清除筛选另占一行，防止排序被挤下。详情缩紧间距，正文不裁切。

### 来源与采集展开区

展开区只呈现来源操作、目录与采集状态，不再嵌套完整内容工作台。优先添加来源，再导入单条链接，最后管理分类；高度随内容增长，避免固定高度和多层滚动。复用原来源行与对话框，验证、同步、监控、删除确认、运行历史及归属校验不变。目录与概览桌面并排，窄屏堆叠，所有数字来自真实 workspace。

## 选题中心操作顺序

“01 补充选题 → 02 挑选候选 → 03 核对选题 → 04 立项创作”。已有候选时直接进入挑选：新增入口集中在可展开的第一步，保留四种 AI 依据、一句话起草、手动录入及今日新增记录。来源过滤收进候选区，统计类来源仍不可假筛选；搜索和排序保持原 URL/查询语义。主体为候选与详情两栏，选中态共享，正文核对后再展示明确立项动作；候选卡操作区仅保留“丢弃”；点击标题查看详情，补充信息和立项集中在详情区。手机按步骤堆叠，使用锚点跳转，按钮可键盘操作。

### 补充选题展开区

按“AI 找方向 / 自己已有想法”分区。四种出题依据保留原 Copilot 深链与预填，进入对话后才发送；当前定位完整换行、其余计数真实展示。一句话起草显示关联的可见标签及保存提示，原创建、加载、防重复和错误逻辑不变；手动详填仍打开原表单。今日新增独立位于下方，窄屏自然堆叠，无固定高度与内部滚动。

### 候选区字体与排版

标题独占一行，17px / 1.6、字重600，不裁切长标题。来源、内容角色及实验标签另起一组，12px起；来源不在属性行重复。观众、形式和状态使用对齐的标签/值结构，值14px、行高1.65；缺失属性不编造。选中卡评分按两列排布，12px起，保留真实未知值。搜索与排序桌面14px、手机16px。沿用本地字体、语义色与键盘焦点；卡片操作仍仅保留丢弃。

## 素材中心

按“搜索 / 上传 → 类型筛选 → 浏览素材 → 预览与操作”组织。类型筛选横向排列并自然换行，真实存储信息收进可展开区域。主体为自适应网格和固定宽度详情，避免重复侧栏挤压素材；平板及手机详情下移，提供原生锚点往返。素材卡显示完整文件名、类型、大小和日期，完整 MIME 保留在元数据里；实际缩略图按原比例展示，未知预览沿用诚实降级。所选文件名在详情顶部明确显示，操作采用两列文字按钮，危险操作单独排列并保留确认。全部 / 按项目 / 回收站保留原过滤、分页和真实操作；项目概览及回收站不显示无关的活跃素材详情。

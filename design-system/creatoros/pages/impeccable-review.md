# Impeccable 全页面修整

适用范围：当前个人独立源码预览；沿用现有工作台设计，不更换产品身份，不修改数据与已安装应用。

本轮依据 Impeccable 4.7.0 的 audit / polish、Operate 模式与 craft floor，先采集截图和可访问性基线，再集中修复，最后核对实际页面。产品目标和受众使用此前用户明确的 CreatorOS 创作工作流与现有设计系统；未建立新的产品方向或编造产品文档。

| 页面范围 | 修整原则 |
|---|---|
| 所有工作台与列表 | 区块标题和操作自然换行；保持统一焦点、间距、文字与状态反馈 |
| 定位中心与定位对话 | 定位字段使用有效描述列表，标题不挤成竖排，调整窗口控件报告当前尺寸 |
| 雷达、选题 | 详情可用键盘滚动，分栏调整报告范围，候选归属说明使用克制分组 |
| 搜索、设置 | 区分筛选与标签页；设置方向键切换，Home/End 到达首尾，内容和控件正确关联 |
| 知识库、实战课 | 导入操作可换行，课程首页与正文采用同一主题变量，保留课程信息和学习行为 |
| 脚本、文章、图文、朋友圈 | 脚本操作保持可读对比与可见性，成稿预览可以聚焦滚动，作品正文与输出尺寸保持原值 |
| 视频编辑器 | 缩放选择框有明确名称；单一播放头滑块避免嵌套控件；标尺支持方向键与 Home/End，时间轴目标至少 24px |
| 总览、发布、复盘、自动化 | 文内链接有下划线，移除装饰性粗色边，保留数据、分析和操作 |

来源分类、模拟标签、版权归属、警告和错误均保留；不隐藏必要信息来获得更干净的截图。宽表、画布、项目阶段条和时间轴允许局部横向滚动，普通正文不可通过裁剪掩盖溢出。

自动扫描不等同于人工屏幕阅读器、真机触摸、真实 AI 或第三方发布验证。检查详情与限制见工作区 outputs/CreatorOS-impeccable-report.md。

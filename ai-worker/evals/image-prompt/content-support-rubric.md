# 内容辅助型文生图评尺 v1

用途：匿名评分口播 B-roll 的画面槽位与 `generationPrompt`。只判断图片是否推进理解及提示词是否可执行，不评价成图模型本身的审美上限。

## 硬失败

出现任一项，总分上限 40：

- 用 AI 生成图冒充真实新闻、数据、产品截图、机构页面或真实人物事件；
- 画面主要靠复述口播、大段图内文字或虚构数字才能成立；
- 只有“科技感、未来感、商务感、AI 粒子、发光大脑、机器人握手、商务人士看电脑”等通用海报元素，没有本题唯一可见关系；
- `generationPrompt` 把 `purpose / reason / visualClaim` 等内部解释当作要画进图里的文字；
- 画面改变了口播事实、主张或因果关系。

## 100 分维度

| 维度 | 分值 | 满分标准 |
| --- | ---: | --- |
| 内容职责 | 15 | 明确选择证据、过程、类比、对比、后果或情绪中的一种；这个选择与当前口播匹配 |
| 认知增量 | 20 | `visualClaim` 说清观众看完新增理解，不是标题/口播同义改写；一个画面只完成一个认知动作 |
| 可见关系 | 20 | 抽象判断被转成具体主体、动作、空间、物件或前后关系；换到别的主题就不能原样套用 |
| 因果理由 | 10 | `reason` 说明为什么画面比继续看人物或字幕更能解释此句，不用“更生动/更吸引”占位 |
| 生图可执行性 | 15 | prompt 清楚描述媒介、主体、动作/关系、环境、构图，并按需给光线/色彩/画幅；模型无需猜核心画面 |
| 事实与文字纪律 | 10 | 事实证据不生成；正文配图默认无文字/数字/logo/水印/假界面；必要文字转截图或信息卡 |
| 定位边界 | 5 | 定位只影响观众熟悉度、信息密度和视觉语气，不增加事实或改写主张 |
| 表达效率 | 5 | prompt 简洁、没有关键词汤、互相冲突的风格词或重复约束 |

## 评分输出

每题输出：

```json
{
  "label": "A|B",
  "total": 0,
  "hardFail": false,
  "hardFailReasons": [],
  "dimensions": {
    "role": 0,
    "cognitiveGain": 0,
    "visibleRelation": 0,
    "reason": 0,
    "executability": 0,
    "truthAndText": 0,
    "positioningBoundary": 0,
    "efficiency": 0
  },
  "decisiveIssue": "一句话"
}
```

同题 A/B 标签必须随机化。评委不知道版本映射；生成者不得兼任评委。

## 晋级门

- 三题平均分相对基线至少 `+8`；
- 每题变化不低于 `-3`；
- 新版零硬失败；
- `认知增量 + 可见关系 + 生图可执行性` 三项平均不得下降。

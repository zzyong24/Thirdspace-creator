# 模拟数据边界

真实业务交付以已确认契约和真实数据链路为准。测试可以使用可复现的合成数据、固定时钟和替身；它们留在测试注入边界，不能作为运行失败后的产品兜底。

临时用于开发演示的夹具，在 `MOCK_DATA_SPEC.md` 记录消费位置、接真任务和退出条件。独立回归测试夹具无需退役，没用模拟数据时不建空账本。参考 `templates/MOCK_DATA_SPEC_TEMPLATE.md`。

读失败显示真实错误，不能 `catch` 后返回假成功数据。写后读必须使用同一真实归属；日期、用户、路径等非数据层常量同样不能让产品停留在演示状态。API 适配或测试注入沿用项目既有边界，不为单次调用强制新增封装层。

`gates/08-mock-data-gate.md` 检查实际使用方式，整体联调核对临时演示依赖已移除。模拟测试通过只证明对应局部行为。

# 界面候选图说明

仅在需要视觉探索或生成候选图时使用。内容来自页面规格和产品词汇，样式来自当前界面规范或明确的探索任务；候选图不能自己变成产品需求。

```text
场景：<桌面/移动端及业务目的>
画布：<视口、比例、单屏或总览>
用户目标：<角色要完成的结果>
信息优先级：<主要、次要与辅助内容>
页面：<用户名称；内部来源编号不渲染>
布局与控件：<区域关系、准确文案与状态>
数据：<有来源的示例或空/加载/错误状态>
视觉来源：<路径/链接/哈希，或探索候选>
样式：<项目颜色、字体、间距、图标、组件>
保持：<已有层级、含义和不变区域>
可变化：<明确的探索变量>
限制：不增加未确认功能，不显示内部编号；未要求时不加水印或设备外框。
```

用户要求选风格时，为代表页面提供少量有明确差别的候选，记录实际选择及来源。已有方向或用户授权 Agent 决定时，直接按授权推进，不额外增设选图关卡。工具不可用时说明实际替代方案，不静默声称使用了原工具。

多屏总览覆盖实际声明的模块；新想法标为提案，范围处理后才能实现。内容缺陷回写产品/页面定义，不只改提示词。候选图保存在项目设计证据中，正式采用后同步界面规范。

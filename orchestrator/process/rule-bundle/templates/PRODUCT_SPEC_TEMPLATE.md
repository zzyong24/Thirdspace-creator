# 产品总纲

> 产品方向、确认范围与稳定 ID 的真相源。面向用户的词和状态句式由 `PRODUCT_VOCABULARY.md` 决定；不得为了文案改写 `FR/FLOW/ENT/IA/AC/HARD/PKG` ID。

## 使用方式

- S：直接填写本文件，短而具体；不适用的模块拆分写 `Not split`。
- M/L：本文件只保留全局方向、边界和模块地图。模块局部行为/数据/UI/AC 写入 `docs/features/<module>/`，跨模块旅程写入 `docs/journeys/`，横切基础写入 `docs/platform/`。
- 深度由证据与风险触发：只有高影响假设、未知外部能力、复杂状态、不可逆数据、安全/合规或真实可行性疑点需要加深。普通小工具不为“看起来完整”预填仪式表格。
- 事实引用用户输入、现有工件、代码/运行证据或显式假设。证据不足时记录假设或开启有界研究，不用空话补齐。

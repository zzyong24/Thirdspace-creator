# PAT-001 — Borrow-before-Build（先借后造）

用于现有能力不能直接满足需求时的重大依赖、适配、fork 或非平凡自研取舍。普通实现先用 [公共规则的最小实现阶梯](../../rules/global-rules.md#最小实现阶梯)，不必打开本卡或创建决策记录。

## 1. 触发与范围

- 需要引入新依赖、复制外部资产、修改上游源码，或拥有一段长期维护的通用实现。
- 已发现现有方案的具体缺口，需要比较适配成本与自研成本。
- 小段领域胶水直接实现；不按代码行数决定是否需要选型。属于核心差异化也不意味着所有底层都要自研。

## 2. 采用方式

保留原有档位，供既有决策引用；它们描述集成深度，不是每次必须走完的审批流程。

| 档位 | 含义 | 适用条件 |
|---|---|---|
| T0 直接采用 | 调用已有实现/库/服务 | 当前合同已满足 |
| T1 薄适配 | 仅转换确有差异的接口/数据 | 存在可指明的语义差异；不默认给每个库套接口 |
| T2 fork | 修改上游源码 | 公共 API/组合无法满足，且能承担维护与升级 |
| T3 自研 | 最小必要实现 | 已证实已有方案不适用，或总体维护成本更低 |

当前工程、标准库、原生平台、已安装依赖优先。仅当这些不够时才检索相关技能资产或公开生态；索引命中后仍核对 ENTRY、接口、版本、许可证和当前项目验证，`verified` 不代表对所有项目都适用。

新依赖不一概禁止：复杂协议、密码学或标准解析等能力可采用成熟维护实现。比较接入、包体、运行环境、维护和退出成本，避免因“零依赖”而重造危险组件。

## 3. BORROW-GATE：采用前核对

- **BG-001 许可**：外部代码/依赖的使用和分发方式允许。
- **BG-002 维护**：目标版本和维护状态能支持项目期限；不以统一提交频率判死刑。
- **BG-003 适配**：实际 API、输入输出、错误语义及目标平台满足当前验收；热度不是正确性证据。
- **BG-004 风险**：依赖树、已知安全问题和数据边界符合实际项目约束。
- **BG-005 缺口**：明确未覆盖的要求及最小适配；不用未校准的覆盖率百分比替代判断。
- **BG-006 退出**：了解替换成本；只有真实边界需要时才隔离，不预建通用 adapter。

## 4. BUILD-FORCE：何时考虑更深实现

- **BF-001** 核心差异确实无法由现有能力组合表达。
- **BF-002** 候选存在已验证的合同缺口，且适配不合算。
- **BF-003** 必须修改上游语义；比较 fork 与最小自研。
- **BF-004** 运行平台、许可、性能或部署硬约束无法满足。
- **BF-005** 有依据的全周期成本比较支持自研。

这些是比较触发器，不是自动强制自研。证据不足时查相关源码/官方接口或做一个小探针；未知不等于不支持。只有重复机制不明的阻塞才进入既有 Research-First Gate。

重大取舍沿用项目现有 DEC，写明候选、具体缺口、选择及验证。普通复用无需记录；经验账本只收录实际观察到的可复用教训，不与每次 DEC 强制双写。

## 5. 情境校准

| 情境 | 应有选择 | 不能省略 |
|---|---|---|
| 普通日期输入，项目无现成组件 | 原生日期输入 + 项目必需的绑定与反馈 | 标签、实际日期约束、提交和错误反馈 |
| 工程已有满足合同的 DateField | 复用现有组件 | 核对其参数与校验语义 |
| 明确要求区间、多日期或特殊日历交互 | 核对现有依赖；必要时选库或最小自研 | 明确需求不能被简化成单日期 |
| 标准编码、路径或日期格式化 | 当前版本的标准库/平台 API | 边界语义和输入校验 |
| 不可信路径拼接、复杂安全协议 | 选满足安全合同的实现 | 不能以一行代码替代边界验证 |

以上是评估情境，不是已完成的模型行为测试。验证应看验收通过、新增依赖/抽象和真实维护成本，代码行数仅作辅助指标。

## 6. 来源与采用边界

2026-10-08 核对 [Ponytail 原始技能](https://github.com/DietrichGebert/ponytail/blob/main/skills/ponytail/SKILL.md)及其[作者基准报告](https://github.com/DietrichGebert/ponytail/blob/main/benchmarks/results/2026-06-18-agentic.md)。本库吸收其有序选择与理解先行原则；将“一行实现”合并进最小增量，不照搬人格、强度模式、固定输出长度或单测试限制。

报告中的日期输入 404→23 是 Haiku 4.5 在指定 FastAPI/React 仓库、每任务/组四次运行的平均新增行数。功能任务没有启动服务或浏览器；安全样例执行了定向检查。这是作者的特定实验，不能推出 Astra 的收益，也不是完整功能或安全证明。

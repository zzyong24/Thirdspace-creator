# 三态熔断接入说明

核心实现位于 `example/portable-slice.mjs`；来源与版本见上一级 `ENTRY.md`。按实际健康隔离边界维护熔断器，不因示例引入额外业务层。

Closed 达到失败阈值进入 Open；超时后进入 HalfOpen 并允许有限探针；探针成功达到门槛后关闭，失败重新打开。时钟和预算由调用方提供。

取得 `allow()` 的半开许可后，必须恰好调用一次 `recordSuccess`、`recordFailure` 或 `releaseNeutral`。非上游健康失败应走中性释放。不要先为整个候选列表预领取许可，再只尝试其中几个：提前成功或截断列表会泄漏未使用许可。应在实际尝试该候选前领取，退出时结清。

是否需要按应用隔离、半开探针或多上游路由，取决于真实故障模式。简单重试够用时不套用此模式。具体行为由资产测试验证，目标项目仍需覆盖其自己的取消、提前成功和异常路径。

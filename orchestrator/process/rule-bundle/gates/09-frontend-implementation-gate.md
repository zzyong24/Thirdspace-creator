# 前端实现检查

> 适用判定与证据格式见 [_GATE_EVIDENCE.md](./_GATE_EVIDENCE.md)。

- 行为对应当前需求与页面合同，核心路径和重要状态有适用验证。
- 未接线的控件标明规划中并有任务所有者；不把空壳显示为已完成能力。
- 真实写入后读回同一实体。读取失败显示可处理的错误，不静默使用 fixture。
- 跨页状态名称、格式和时间语义由一处维护，沿用产品词表。
- 用户可见文本不泄漏任务/规格/测试 ID（如 `T106`、`API-203`）、内部 schema/enum、来源项目或工单信息；技术产品确有用户语义的术语按项目词表处理。现有程序检查的限制应如实报告，不改测试来隐藏泄漏。

源码搜索是预警，真实旅程的可见文本证据才支撑验收。执行层面的要求见 [界面实现规则](../rules/ui-implementation-rules.md) 与前端验证门。

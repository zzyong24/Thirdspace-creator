# 整体验收

> 适用判定与证据格式见 [_GATE_EVIDENCE.md](./_GATE_EVIDENCE.md)。

- 前后端合同、数据与用户主线一致，发布关键路径有真实端到端证据。
- 涉及操作系统时，在每个目标系统通过最终安装产物观察实际效果，核对命令/API、参数路径、退出或回调完成和用户文案；单元测试、安装文件名或开发态运行不能冒充目标安装版证据。
- 已启用追溯时，发布范围内 PLANNED 收敛为 OK 或有 DEC 的 DEFERRED/RISK；实际存在模拟退出记录时核对消费者已迁移。休眠材料不产生空表义务。
- 用真实数据走跨页面主线，包含返回、刷新和上下文交接；局部收据的集合不等于整体通过。
- 已完成 UI 任务保留有效 `PASS:<report-hash>`；reconcile 核对 watched_paths、合同、报告和收据变化，无关提交不自动作废所有历史结果。
- `program_completion_required=true` 时执行 `program-gate.mjs --execute`；缺配置是错误，不能以文件不存在退出跨项目验收。GO 绑定当前 FLOW、部署版本集合和真实证据。
- 用户用语唯一维护。部署运行的可观测性按 `rules/observability-rules.md`：从安全的失败场景用“参考编号”找到对应结构事件，核对状态、耗时和敏感数据排除。
- 超时链路按 [timeout-budget-rules](../rules/timeout-budget-rules.md) 验证完整外层预算与恢复；观察结束不冒充后台失败。

记录当前代码、命令结果、真实主线、已知风险及处置。发布动作核对已有用户授权；没有授权时完成可审查准备，再请求批准。

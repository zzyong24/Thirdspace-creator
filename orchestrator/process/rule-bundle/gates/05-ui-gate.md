# 界面方向检查

> 适用判定与证据格式见 [_GATE_EVIDENCE.md](./_GATE_EVIDENCE.md)。

- 项目有明确视觉依据、可访问性与响应式要求。沿用用户已选方向；普通可逆细节可采用说明过的默认值，重要未决偏好才确认。
- 生成或还原只使用当前项目已选且可用的工具/模式；未配置时不假定存在。结果回到 `UI_RULES.md`，供应商默认不成为产品要求。
- 交接说明区域、组件、状态、真实代表内容和视口；与已选参考对照，不能以模型自报代替检查。
- 设计稿额外出现的页面或功能须删除或走真实范围变更，不因图中存在就进入实现。
- 用户文案服从 `PRODUCT_VOCABULARY.md`，不出现控制面 ID 或实现术语。

证据包括视觉依据或可逆默认值、实际对比和范围差异。无需为每张图增加一次确认。

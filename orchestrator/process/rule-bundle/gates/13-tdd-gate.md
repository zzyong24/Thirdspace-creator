# 实现验证检查

> 适用判定与证据格式见 [_GATE_EVIDENCE.md](./_GATE_EVIDENCE.md)。

缺陷、核心业务、parser、数据和安全边界等确定性行为，应有能捕获缺失行为的 RED，再实现至 GREEN。纯样式、文档、生成物和无可执行行为的配置不制造失败测试；使用视觉、类型、语法或冒烟检查。UI 状态与交互仍需适用测试。

仅在已触及代码有收益时做行为不变整理；实际修改后重跑聚焦验证。清理不得扩大 write_set、添加行为、改公共契约或数据归属，必要变化回到当前任务范围判断。

首次测试即通过时核查它是否覆盖了待修行为，不为制造红色结果破坏正常代码。不得排除失败用例、放宽断言或伪造过去的 RED。

共享代码变化扩大相关回归；真实数据、UI 状态和跨层链路变化运行真实旅程。操作系统集成按 platform_execution_matrix 核对命令/API、无 shell 参数路径、完成语义、不支持情况和用户文案。

超时相关改动按 [timeout-budget-rules](../rules/timeout-budget-rules.md) 验证完整公共入口及恢复状态，模拟不代替真实平台证据。

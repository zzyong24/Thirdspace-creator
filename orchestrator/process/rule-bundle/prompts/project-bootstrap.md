# 首次建立可运行基线

首次 BUILD 前执行一次；已有可运行基线就直接复用。选择用户指定或项目现有技术栈，缺省时采用合适的可逆方案，有影响的选择记录在决定中。

建立最小可运行骨架，配置项目适用验证并运行有意义的冒烟检查。用第一个真实回归用例确认失败检测，不添加随后删除的仪式测试。实际测试和构建通过后，将安装、运行、测试、单测、构建命令及执行目录写入 `PROJECT_CONTEXT.md`。

Agent 产品初始化或替换内核时，复用 CONTRACT 根据 [Agent 初始化架构](agent-architecture-initialization.md) 形成的决定，验证内核、工具、业务读回。设计缺失时先在已有架构/契约补足；已有证据不重复调研。

外部凭据或服务阻塞时，可继续与它无关的本地工作，依赖真实内核的验收仍保持未验证。模拟契约通过不能写成真实运行成功；循环能力可用隔离集成测试验证，不为业务强制增加工具调用。

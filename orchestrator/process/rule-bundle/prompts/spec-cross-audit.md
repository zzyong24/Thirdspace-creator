# 跨模块规格核对

产品、契约或页面说明拆成多个模块，且将共同指导实现时使用。它检查跨模块含义和依赖，不要求每个项目启动正式评审或子代理。

## 输入与检查

读取当前总纲、实际模块集合、相关合同和已有决定。核对范围、ID、术语、状态、权限、模块所有者、页面操作绑定是否一致；同一事实引用唯一维护位置。

已启用 ID_REGISTRY / TRACEABILITY_MATRIX 时核对其引用；休眠追溯不要求为此次核对创建空表。只检查阶段门所需字段及被实际声明或风险触发的字段，未触发的模板章节不是缺陷。

## 修复与交接

在授权范围内直接修复错链、错字、术语不一致和已明确决定的遗漏。涉及新产品范围、数据归属或公共契约的重要未决选择，说明冲突、候选和建议，按公共流程处理。

可以由主会话完成。若委派，遵循派发和隔离规则；审查者不修改主控制面，主会话整合 ID 与状态。返回实际问题、依据、修改路径和待决事项，然后运行受影响的检查，不例行重跑无关验证。

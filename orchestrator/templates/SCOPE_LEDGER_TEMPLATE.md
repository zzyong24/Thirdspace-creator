# Scope Ledger(范围预算累计账本)

> 消费方:`gates/03-scope-budget-gate.md`。计量单位 = BACKLOG 任务;**拆任务不重置预算**——同一 FR 家族 30 天内累计。膨胀最常见的绕行是 salami slicing(一个功能切三刀,每刀单看都在预算内),这本账就是为它记的。落点:`<project>/orchestrator/SCOPE_LEDGER.md`。

## 记账规则

- 每个过 CONTRACT 门的任务记一行(PLAN 端气味触发的也记);**未触发预算线也照记**——家族累计要用。
- FR 家族 = 同一 FEAT / 同一宪法能力条目下的 FR 集合;家族名用宪法或 FEAT 的稳定叫法,不许当场发明新家族名稀释累计。
- 计数口径以 gate 03 为准(从源工件逐项可枚举:JSONB 语义列照计表、enum 分支照计操作)；
  当前由 gate 执行者核对明细，不能冒充已有通用机器计数器。
- 豁免(B 案)必须带 DEC 链接;**同一家族第 3 次豁免 → 升级宪法级复审**(gate 03 规则)。

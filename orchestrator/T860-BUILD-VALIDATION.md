# T-860 BUILD 验证记录

## 用户反馈与根因

用户在 T-859 v6 竖屏预览中指出：横版录屏的可见底边与左下人物框的上边发生重合。

1080×1920 画布内，横版录屏采用 `contain` 后的真实可见范围为 `y=556..1164`；旧人物框从 `y=1090` 开始，因此实际压入素材 74 像素。这不是素材文件问题，而是人物框几何没有按素材的真实可见边界避让。

## 修复

- 人物框由 `320×569 @ (54,1090)` 调整为 `264×469 @ (54,1188)`。
- 素材底边与人物框上边保留 24 像素可见间隔。
- 人物框底边与双语字幕安全区继续分离。
- 正式渲染安全门同时拒绝“人物压素材”和“人物压字幕”两类布局，避免后续素材比例变化时再次静默产出重合画面。

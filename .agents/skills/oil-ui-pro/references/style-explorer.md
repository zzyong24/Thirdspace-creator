# 风格对比页

## 固定外壳，独立候选

用内置 [模板](../assets/style-explorer.html) 展示实际小样。外壳参照专业选片工具，采用无色相的浅灰画布和系统字体，让作品本身最突出，也便于判断颜色；左上角是 Oil UI 的标志和字标，点击会在新标签页打开 oiloil.org，品牌黄只用在标志、选中标记和复制提示这几处小面积。它只承担比较和挑选的功能，不带风格倾向，也不作为候选的参考。并排视图只负责比较画面：每个方向等大排列，作品下方只有一行编号、名称、色条和“选择”，再加两行以内的北极星，也可以关闭说明只看作品。色值、字体和特征放在单张查看的侧栏里。模板负责并排与单张查看、候选筛选、统一视口、实际尺寸、选择即复制与备注；每个候选在独立框架中渲染，其 CSS 不影响其他候选和外壳。

默认并排且等大，保证比较公平。点击任一画面进入单张查看：画面从卡片放大到主区域，右侧栏滑入，栏顶是方向列表，下面是该方向的完整说明；键盘 ← → 让画面整条左右滑动切换方向，P 选定，Esc 缩回并排。

外壳的动效只服务于看清变化：分段控件和方向列表用滑块移动表示当前项，视图之间用同一画面的放大与缩回保持连续，切换视口、筛选和缩放时外框直接变形，不做叠影；选定时标记弹出确认。控件用短促的咔嗒手感，画面切换用平滑减速，系统开启“减少动态效果”时全部直接到位。

先保持核心内容、主要动作和目标用户一致，再改变构图、信息组织、字体气质、色彩关系、密度与图像语言。数量按请求和有效差异决定，不复制整个产品来凑方案，也不把内置外壳的风格套给候选。

对比页是视觉探索工具。HTML 小样默认不执行脚本和提交，标记为可操作的小样和本机地址候选除外（见“准备输入”）；需要真实数据、登录或后端的交互验收，仍在项目里进行。

## 准备输入

在任务目录放置 `manifest.json` 和候选文件。HTML 候选为带 `head` 的文档，CSS 写在页面里。图片、字体和视频用相对路径引用任务目录里的文件，例如 `img/hero.jpg`，生成器会把它们内嵌进对比页；不要自己把图片转成 base64 写进候选，文件会变得很大、难以修改。不引用网络资源和任务目录以外的文件，链接只使用本页锚点。可以保留代码供独立打开，但比较页不执行其脚本。

候选必须在不运行脚本时也能显示设计内容。依赖脚本生成界面的页面，先取得静态 HTML 或实际截图；不能把只有空挂载节点的应用入口交给对比页。

候选内部不使用 iframe、object 或 embed 等嵌套文档；先将需要的内容转为静态页面或截图。另存的现有页面常带 `srcset` 或 `<picture><source>` 响应式图片，生成器会拒绝：改成一张用相对路径引用的 `<img>`，或直接用截图作为图片候选。

图片候选支持 PNG、JPEG、WebP。实际查看图片并记录它代表的页面与状态，避免拿不同任务或不同状态的图比较风格。源文件必须位于 manifest 同目录或子目录。

manifest 使用固定字段，结构如下。尖括号内是占位说明，全部换成本轮方向卡里的实际内容；不要沿用占位文字作为风格：

```json
{
  "schemaVersion": 1,
  "project": "<项目名称>",
  "brief": "<所有候选共同表达的内容与主要任务>",
  "round": "<轮次，例如 01>",
  "candidates": [
    {
      "id": "<小写唯一标识>",
      "name": "<方向名称>",
      "concept": "<北极星：一句能指导取舍的体验意图>",
      "typography": "<实际使用的字族、字重与尺度关系>",
      "palette": ["<十六进制色值>", "<十六进制色值>", "<十六进制色值>"],
      "traits": ["<可观察特征>", "<可观察特征>"],
      "kind": "html",
      "source": "<候选文件的相对路径>"
    }
  ]
}
```

自己写的可运行小样（单个 HTML、脚本内联），在 manifest 里给候选加 `"interactive": true`。单张查看时就能直接操作，对比页仍是可离线移动的单个文件，不需要服务器；卡片左下角标注“可操作”。这类候选只能运行内联脚本，不能联网或加载外部文件；浏览器存储换成页面关闭即清空的内存版本；`alert`、`confirm` 这类系统弹窗不会出现，需要确认时用页面内的对话框。

已有仓库里要运行起来的应用（例如 React、Vue 项目），把 `kind` 设为 `url`，用 `url` 字段代替 `source`，指向本机开发服务器上的页面，例如 `http://localhost:5173/orders?variant=b`。这类候选在对比页里实时运行，脚本和表单照常工作，切换手机视口时应用会真实重排；卡片左下角标注“本地运行”。地址只能是 localhost、127.0.0.1 或 ::1；页面空白时，确认开发服务器已启动，且没有用响应头禁止被嵌入。对比页离开这台机器、或开发服务器关闭后，这类候选就看不到了，需要留存时另存截图作为图片候选。多文件的小样确实需要服务器时，用只监听本机的静态服务器，并用 `--directory` 只暴露任务目录，例如 `python3 -m http.server 8765 --bind 127.0.0.1 --directory <任务目录>`，看完就关掉。

给当前版本加 `"baseline": true`，它会排在第一位，编号显示为“现状”，其余方向从 01 开始编号。每轮最多一个基线。改动存量页面时，都把现状放进来，让每个方向都和它对照。

`id` 使用唯一的小写字母、数字、连字符或下划线。`typography` 描述实际使用的文字关系，`palette` 使用十六进制颜色，`traits` 简述可观察差异。图片候选将 `kind` 改为 `image`、`source` 指向对应图像。

## 生成和打开

确认 Python 不低于 3.10，将脚本与输入输出参数解析为绝对路径后运行 [生成器](../scripts/build_explorer.py)：

```text
<python> <skill>/scripts/build_explorer.py <任务目录>/manifest.json --output <任务目录>/style-explorer.html
```

macOS/Linux 通常使用 `python3`，Windows 通常使用 `py -3`；执行前确认实际解释器。没有生成器运行能力时保留输入与候选供直接查看，说明尚未组装对比页，不临时重写另一套工具。

默认拒绝覆盖。确实要更新已有本轮对比页时显式加 `--force`，或使用新的输出文件名。输入错误时保留旧产物；生成器不覆盖源候选，也不允许把运行产物写入 Skill 目录。

用浏览器打开返回的本地 HTML，无需服务器和联网。输出已内嵌候选，移动单个 HTML 仍可查看。模板原文件只有空状态，不是用户最终对比页。

## 查看与记录选择

默认使用相同逻辑视口展示 HTML 候选：桌面 1280×900，手机 390×844。卡片等比缩放以便同屏比较；判断文字大小与细节时进入单张查看，使用“实际尺寸 100%”检查真实排版；适应窗口仍可能缩小，不能据此宣称可读性通过。切换手机视口后确认真实重排，而非仅看缩小后的桌面。

用筛选入口保留想同时比较的方案。选定一个方向，按需记录喜欢的特征与需要调整的部分。选择和备注保存在浏览器；存储不可用时界面保留当前会话，并仍可复制。当前选择和备注在顶部栏右侧，不另设底部栏，也没有单独的复制按钮，把高度留给作品。

生成器根据本轮项目和候选内容生成 `fingerprint`。候选内容变化后会形成新一轮存储身份，避免把旧选择误用于新作品。点“选择”时同时复制一句简短的文字：轮次、编号和方向名，有备注时再附一行，例如“<轮次>：选 03 <方向名>”，并在底部提示已复制的内容。改完备注后再点一次“已选择”重新复制；选另一个方向会直接替换当前选择。

用户粘贴复制的结果或直接说出选择后，Agent 按轮次和编号对照当前 manifest，确认对应本轮，再把选择与备注更新到项目设计说明，继续实现。浏览器本地保存不代表已经写回项目文件，也不会自动向 Agent 发送消息。

## 检查实际结果

检查候选内容是否可比，元数据与画面是否相符，以及中文字体是否真实可用。确认并排、单张查看与切换、筛选、桌面/手机、实际尺寸、返回并排、选择恢复和选择即复制都能操作；检查窄屏与存储不可用情况。

只有模板、生成器或其接口变化时运行 [程序回归](../tests/test_build_explorer.py)：

```text
<python> -m unittest discover -s <skill>/tests -v
```

程序回归验证内嵌、输入校验、覆盖保护、目录迁移和模板功能入口；实际视觉与交互仍需浏览器查看。普通新增候选只核对该轮内容和页面，不每次重跑模板全套测试。

## 修改模板本身

模板的功能是本 Skill 对用户的承诺：并排与单张查看、桌面与手机、筛选、设计说明开关、实际尺寸、选择即复制、备注、本地地址候选与现状基线，以及存储不可用时的提示。调整外观时这些功能一项都不能少；确实要删减，先同步修改本文件、README 和回归测试。

直接编辑 `assets/style-explorer.html`，不要在任务目录写一次性脚本去替换模板里的字符串。改完运行程序回归，再用浏览器实际走一遍单张切换、选定复制、备注和返回并排；改动效时放慢播放，截取过渡中间的画面检查有没有叠影和跳动。

# CreatorOS 视觉规范(T-054,锚 = 今日台水准,用户 2026-07-03 拍板)

> 标杆截图:`baseline-newia/01-today.png`(今日台)与 `02-works-candidates.png`(候选 tab)。全站推平以这两张的密度、留白、层级为准。token 单一真值 = `frontend/src/app/globals.css`(130 变量),**禁止硬编码色值/圆角/阴影**。

## 1. 版式

- 页面内容区统一 `max-w` 与左右留白跟今日台一致;区块间距 gap-4~6,卡内 padding p-4~5,不出现挤成一团或大片空白。
- 卡片:`rounded-card border border-border bg-surface`;悬浮态 `hover:border-brand/50`;**不叠双边框、不叠双阴影**。
- 页头:每页一个 h 级标题 + 一行副描述,**绝不双头**(shell 标题与页内大标题二选一,embedded 范式)。
- 工作台类(候选/裁决台/稿面)固定高度框内滚;文档类(设置页签)自然流。

## 2. 文案(最常见的丑)

- **禁止开发者说明文案泄漏 UI**:「TipTap 富文本编辑器:可改标题/加粗/列表」「标签、平台在发布时选」这类实现描述/规划注记一律删或改为用户视角一句话(「写你的口播稿」)。判据:句子里出现库名/字段名/机制名 = 泄漏。
- 空态 = 引导:一句现状 + 一个行动(链接/按钮),不留灰杠占位、不留纯「暂无数据」。
- 按钮动词化(「保存节奏」「登记已发布」),状态徽章名词化(「已发布」「待裁决」)。
- 中文与数字/英文之间不加多余空格混排怪象;时间统一 YYYY-MM-DD。

## 3. 控件

- 编辑器/工具栏按钮用 lucide 图标(Bold/Italic/Strikethrough/List…)+ tooltip,不用文字按钮。
- 表单输入统一现有 Input/Textarea 组件;内联表单(非弹窗)是默认;**Dialog 只用于确认类小交互,承载页面内容的 Dialog 违规**。
- 徽章色语义:成功 green / 警示 amber / 危险 red / 品牌 brand,不混用。

## 4. 结构级裁决(本轮)

- **设置从 Dialog 改整页**:/settings 是一级导航,内容(定位母版/校准规则库)是富文档,居中弹窗装不下——改为整页左侧页签 + 右侧内容布局(参照今日台版心),Dialog 壳退役。⌘, 快捷或头像菜单进入同一页面。
- 稿面右栏编导对话保持;左稿面各区文案按 §2 清洗。
- 侧栏「当前项目」区不显示重复占位(项目名重复两行的收敛)。

## 5. 验收方式

每片改完:1440×900 截图与 baseline 同名对照落 `frontend/docs/t054-ui/after-newia/`;主会话亲自看图判定;文案泄漏用 grep 复扫(TipTap|富文本|规划中(用户可见处)|字段名)。
